# 羽轩编程工作台 2.2.0

Windows x64 本地编程平台：App Inventor、Mixly 2、Python、C++。

请从 Releases 下载完整安装包 `AppInventor-Offline-Setup-x64.exe`。首次使用需联网激活，后续在授权有效期内可离线使用。

本版包含 App Inventor 本机 APK 构建和 USB 调试入口、Python 图形库、第三方库搜索的证书修复、Python 环境准备优化和 C++ 编译缓存。

[使用说明](docs/使用说明.txt)。`distribution-source/` 为适配源码，`build-tools/` 为构建辅助脚本，`validation/` 为验收脚本。完整上游源码与适配交付包见本版本 Release。

各上游项目保留其原许可证，请参阅 `licenses/` 及文件头。源码快照不含完整预构建运行环境，构建前需按源码包交接说明准备依赖。

真实开发板串口与 Android 真机未验证。
