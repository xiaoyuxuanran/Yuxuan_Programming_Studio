羽轩编程工作台 2.3.3 — Windows x64

2.3.3 新功能与升级
主页面提供“更新日志”和“检查更新”。联网优先检查 Gitee 最新正式版，无法访问时自动回退 GitHub，显示更新内容；选择下载后校验 SHA256，确认后保存并退出再安装。检查失败时可从发布页面手动下载，不影响现有工具和授权。
2.2.0 可直接使用 2.2.0 → 2.3.3 更新包，无需中间版本；已安装 2.3.1 请使用 2.3.1 → 2.3.3 更新包。保存工程并退出后选择原安装目录，用户数据与激活信息保留。2.3.2 用户使用 2.3.2 → 2.3.3 小型更新包。2.3.0 用户先应用 2.3.1 增量包，再使用本次对应更新包。首次安装可先安装完整 2.2.0，再应用本次直升包。
App Inventor 左侧“优质扩展”提供 MqttTCP、BluetoothLE、ClientSocketAI2Ext，打开项目时自动准备。直接双击或拖动组件即可使用；已有同名或同类型扩展优先保留，组件图标使用本地资源。导出 AIA 时会包含项目中的扩展依赖。
在 App Inventor 逻辑设计中，将已有积木拖到左侧模块面板后松开即可删除；Ctrl+Z 可撤销。拖到其他区域不会按此规则删除。
Mixly Arduino ESP32 通信分类提供蓝牙初始化、是否有数据、读取、发送字节、发送文本（可换行）。蓝牙串口 SPP 仅适用于经典 ESP32，不适用于 ESP32-C3 / S3；这不是 BLE 服务。初始化设备名称留空时使用 ESP32BT。
本版本未进行真实手机蓝牙/MQTT/Socket 通信或真实开发板蓝牙测试；已验证编辑、代码生成和本机编译。

安装与启动
运行 AppInventor-Offline-Setup-x64.exe，安装后从桌面或开始菜单打开 Yuxuan Programming Studio。
启动器提供 App Inventor、Mixly 桌面编程、Python、C++ 四个入口，点击对应按钮即可打开。启动器保持运行；关闭网页不会停止服务。
Python 3.8.9、Python 3.13.16、Pygame 2.6.1、Tkinter/Turtle、Clang++、Java 和 Android 构建工具全部随安装包部署，不需要另装 Python、C++ 编译器、WSL、Java 或 Android Studio，也不会修改系统 PATH。

首次激活与授权有效期
第一次打开软件必须联网激活。在激活窗口输入你获得的激活码，点击“激活并进入”；未激活或首次使用时离线，四个工具入口都不可用。无需在 App Inventor 用户名框中填写激活码。
激活成功后，启动器顶部显示授权有效期和验证状态；永久授权显示“永久授权”。授权凭证绑定当前电脑及 Windows 用户，后续在有效期内可直接离线启动，无需每次输入激活码。
每次启动会尝试联网验证，运行期间约每 60 秒检查一次；网络恢复时也会触发验证。服务器明确确认授权已撤销、禁用或不存在时，会停止工具并禁止继续进入。短暂网络故障或服务端不可用时，已激活且尚未过期的授权可继续离线使用。
持续离线时，软件按授权中的到期时间、本机时间和已记录的使用时间判断是否过期，到期后禁止使用；明显回拨系统时间也会导致验证失败。请保持系统日期和时间正确。完全离线时无法获知服务器刚发生的撤销。
需要重新输入激活码或手动检查时，点击启动器底部“激活 / 验证授权”，再选择“激活并进入”或“重新验证”。授权保存在数据目录 license\device-license.bin 中；不要将其当作其他电脑的通用离线激活文件。

Python / C++ 代码工作区
左侧为项目文件树，中间是带语法配色的代码区，顶部文件标签切换代码，底部显示运行结果。
右上方“运行”按钮（F5 / Ctrl+Enter）会先保存代码，再运行当前 .py 文件或编译运行当前 .cpp/.cc/.cxx 文件。C++ 默认使用 C++17，编译失败不会运行旧程序。C++ 再次运行会先检查代码及头文件变化，未变化时复用编译结果。
编辑约 1 秒后自动保存；Ctrl+S 或“保存”也可立即保存。外部程序修改文件时会拒绝覆盖，请重新打开该文件。
Python 版本可选择 3.8.9 / 3.13.16，并随项目保存。首次运行从内置 wheel 快速准备独立项目环境及 Pygame，不需要联网。已有环境升级时保留用户安装的依赖。两个版本及不同项目的第三方依赖互相隔离。
新 Python 项目的“图形示例”文件夹中有 Tkinter、Turtle、Pygame 示例。选择示例后点击运行，会打开独立 Windows 图形窗口；窗口不会嵌入浏览器。Tkinter 使用 root.mainloop()，Turtle 使用 turtle.done()，Pygame 保持事件循环，关闭图形窗口结束运行。
“停止”可终止当前程序及其子进程。程序需要 input()/cin 时，在底部输入框输入并回车。
左侧“第三方库”面板支持按准确库名搜索，例如 requests、numpy、pygame；可以安装库名，或指定“库名==版本”。安装使用清华大学镜像源 https://pypi.tuna.tsinghua.edu.cn/simple。搜索与安装使用 Windows 系统信任及内置 CA 证书进行 HTTPS 校验；不会通过关闭证书校验规避错误。搜索与安装新库需要网络；pip 会选择兼容当前 Python 的版本，不保证所有最新库都支持 Python 3.8。
顶部 A− / A+ 缩小或放大代码字体（10–32 px），点击中间字号恢复默认 14 px；也可使用 Ctrl+-、Ctrl++、Ctrl+0 或在代码区按住 Ctrl 滚动鼠标滚轮。运行输出字号同步调整。
左侧最上方的侧栏按钮或 Ctrl+B 可隐藏/显示侧边栏；再次点击当前文件/库图标也可收起，点击图标可展开对应面板。字号和侧栏设置保存在 studio\studio.json，重启或切换 Python/C++ 后保留。
右上角 Light / Dark 切换主题，重启后保留。代码提示支持关键词、代码片段、当前代码中的名称以及部分 Python 标准库成员；Ctrl+Space 打开提示。此版没有断点调试器和完整语言服务器。
“新建项目”保存在本地数据目录；“打开文件夹”输入已有项目的完整路径，直接编辑其中的文件。新文件/文件夹名称支持相对路径。
移除文件会移动到项目内 .studio-trash 文件夹，可在资源管理器中恢复。请先确认项目和当前文件再运行代码。

App Inventor
输入 1–32 位英文字母或数字作为用户名，无需注册或密码；中文、空格、下划线及其他符号不可用。
默认旧布局和蓝白配色。后续手动选择其他布局仍会保存在本机。
在“项目”菜单新建项目，或导入 examples 中的 HelloOfflineTest.aia；在“组件设计”和“逻辑设计”中编辑，使用“打包 → 打包为.apk格式”生成 APK，然后下载到本地。APK 结果窗口已移除扫码下载。
APK 构建使用随包部署的预处理 DEX 与只读构建资源，缩短新电脑首次编译等待；本机最小样例首次构建由106.0秒降至17.9秒，实际耗时随项目和机器变化；含新第三方扩展的项目仍可能需要首次生成该扩展的缓存。构建等待保留有限超时，不会把失败状态当作编译成功。

App Inventor USB 运行与调试
在 Android 手机中打开开发者选项和 USB 调试，用支持数据传输的 USB 线连接电脑，并在手机上允许这台电脑。必要时安装手机厂商的 Android ADB 驱动；开发板 CH340 等串口驱动不能代替手机驱动。
点击 App Inventor 顶部“USB 调试”，在“运行设备”中选择已连接的手机，点击“运行”。软件会保存当前项目、构建 APK、通过 USB 更新安装，并启动应用；之后可点击“读取应用日志”查看运行结果。首次连接或部分品牌的“USB 安装”需要在手机上确认。
待手机授权、离线或断开的设备不能运行；点击“刷新”重新检查。此面板只列出 USB 手机，不使用无线设备或模拟器。
更新安装保留同签名应用的数据。签名不同、旧版本覆盖新版本或手机拒绝安装时，面板显示原因，不会自动卸载手机已有应用。按提示在手机上处理后再运行。
可反复运行当前或不同项目。意外退出后残留的过期临时安装文件会自动清理。手动下载保存的 APK 位于你选择的下载目录。
同时使用其他 Android 工具时，退出本工作台后，另一工具如显示设备离线，可刷新其设备列表，必要时重新连接手机。
此功能提供构建、安装、启动和应用日志；没有 Android Studio 的断点调试器。软件内置 ADB，不需要另外安装 Android Studio。
输入不同用户名共用此电脑上的 App Inventor 工作区。旧版升级继续保留项目、账号内部身份和签名密钥。

Mixly 桌面编程
从启动器打开“Mixly 桌面编程”，使用 2.2.0 同款 Mixly 2.0-rc4 客户端，无仿真入口。保留 AVR、Arduino ESP8266、Arduino ESP32、Python ESP32。
程序自动恢复当前环境的草稿，也可用“文件”菜单显式保存和打开 .mix。退出和切换环境前仍建议保存工程。代码视图的草稿会同时保留积木和手写代码。
从 2.3.x 网页版切回前，请先将网页中的工程另存为 .mix，再在桌面版打开。浏览器原草稿和插件数据不删除；新版网页扩展与旧桌面扩展格式不同，需使用兼容版本。
通过“设置/管理库”获取官方云端扩展库；主下载站不可用时使用米思齐官方 Gitee 备用源。安装新库需要联网；旧的 ThirdParty、myLib、草稿与 profile 保留。
“串口”打开原生调试窗口，支持波特率、文本收发与数值绘图；右上角“关闭 ×”关闭弹窗，串口连接仍可通过下方串口页管理。
“驱动下载”保留 CH340/CH341、CH343/CH9102、CP210x、FT232/FT231 官方下载链接。
ESP32 蓝牙串口仅支持经典 ESP32 的 SPP，不适用于 ESP32-C3 / S3。

退出与备份
先等待编辑器显示“已保存”，再使用启动器的“保存并退出”。App Inventor 会等待正在进行的构建结束；代码程序会停止。
默认数据目录：%LOCALAPPDATA%\AppInventorOffline
App Inventor 数据：config\account.properties、war\WEB-INF\appengine-generated、war\WEB-INF\authkey、war\WEB-INF\keystore。
代码工作区：studio\studio.json（项目记录和主题），studio\projects（新建项目），studio\environments（项目环境），studio\build（C++ 构建结果）。外部打开的项目保存在它原来的文件夹。
Mixly 桌面数据：mixly\drafts（自动草稿）、mixly\profile（客户端设置）、mixly\src（编辑器数据与 ThirdParty/myLib 扩展）。此前网页端 cloud、web-settings 和浏览器站点数据保留。通过“另存为”保存的 .mix 项目位于你选择的路径，也应另行备份。
授权数据：license\device-license.bin。此文件由当前 Windows 用户加密，复制到不同电脑或用户账户不保证可用，换机可能需要重新联网激活。
退出后复制整个数据目录作备份；外部项目也应另行备份。卸载保留用户数据。不要只备份 App Inventor 数据库而遗漏账号配置和密钥；也可导出 .aia。
App Inventor USB 临时安装文件和进程状态位于数据目录 usb，构建缓存位于 cache；它们不是项目备份。运行日志保存在 logs 中，用于排查故障；启动器不显示日志入口。

所有后台服务仅监听本机 127.0.0.1。App Inventor 默认端口 8888，构建端口 9990；占用时自动选择其他端口。代码工作区使用自动分配的本机端口，请从启动器进入。
App Inventor 的 CloudDB、地图、翻译、ChatBot、Web、联网媒体、在线教程与论坛仍依赖网络服务。本版不提供 iOS 构建。
Mixly 的云端库下载与厂商驱动下载页也需要网络。真实开发板的驱动识别、烧录和串口收发取决于设备、接线与固件；本次交付没有连接实物开发板进行验证。
这是基于 MIT App Inventor 源码的独立本地发行版，非 MIT 官方安装程序。源码基线 c76a58ce7d8b9723107ea980046ca95e1ddf936e；许可、适配源码和 Pygame 对应源码保留在 resources 内。
Mixly 集成基于 2.0-rc4（a7d91f1e3c621a3132fb8ea38c92877bb0834830），保留 Mixly Team@BNU, CHINA 作者信息及许可证，来源记录位于 mixly\UPSTREAM.json，适配源码位于 resources\distribution-source\mixly-adaptation。

本次 USB 功能已验证模拟安装、真实 APK 清单解析及本地接口；验收时未连接真实 Android USB 手机，手机端安装、启动和应用日志未做真机测试。
