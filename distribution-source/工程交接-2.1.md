原工程源码和原始 JAR 未被覆盖。Java 适配类通过独立 classes 目录加载：

4. `YoungAndroidProjectService.java`：本地模式也读取 appengine.host，修复原代码写死 localhost:8888 的构建回调地址。
5. `OfflineLoginServlet.java`：仅输入 1–32 位 ASCII 英文字母/数字进入本机统一工作区；取消密码校验，保留 CSRF 和 loopback 限制。沿用 account.properties 的旧 email 身份保留项目，username 作为显示名。

启动器首次准备可写 WAR，分别生成 authkey 和 keystore。安装包不携带开发环境服务密钥、测试账号、数据库或明文密码。关闭服务前等待构建完成并刷新本地数据库；Windows Job Object 管理子进程。

旧 AAPT 的 ZIP 库不支持中文路径。数据路径含非 ASCII 字符时，启动器用 Windows DefineDosDevice 创建当前登录会话的临时目录别名，编译使用该别名下的 temp/cache，实际数据位置不变。正常退出精确移除本次映射；不修改持久盘符配置。API 依据：[Microsoft DefineDosDeviceW](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-definedosdevicew)。

首次无签名凭证时，即使全程离线也拒绝启动工具。激活一次后有效期内可离线启动；每60秒检查有效期，网络恢复触发在线检查。服务器明确返回撤销、禁用或不存在时清除离线凭证并停止工具；暂时网络故障和服务端不可用时，尚未过期的签名凭证继续有效。凭证绑定机器、产品、设备公钥和许可证ID。服务器补丁仅对 my_computer 发放长期签名凭证，其余产品沿用原短期协议。
