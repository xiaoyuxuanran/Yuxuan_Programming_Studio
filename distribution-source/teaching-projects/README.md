# 教学项目功能预览（基于2.3.3）

在 App Inventor 的项目选择页，用上方的“我的项目 / 教学项目”按钮切换。

- 教学项目左侧按原先确认的56课大纲组织8个阶段、56个课次文件夹。
- 文件夹显示中文，格式为 `No.课次课程主题`。第19课为 `No.19接物游戏：基本玩法`。
- 第19课提供“完整答案”“课堂支架”“纯界面起始版”，可直接打开或下载AIA。
- 其余55课只有空文件夹，不创建空壳工程，也不声称已完成课程内容。
- 右侧课程路线占桌面内容区约50%，可点击阶段导航；仅在教学项目视图显示。在小于等于760px的窄窗口上下排列。
- 内置样例始终保留原版。打开时建立或继续对应的个人可编辑副本，之后打开会保留修改；副本可以在“我的项目”管理。放入回收站的副本不会被自动恢复或覆盖。

## 中文命名的原因与本次处理

原版 `TextValidators.isValidIdentifier` 要求工程名匹配 `^[a-zA-Z]\w*$`。工程名还参与导入路径、项目内部包名等标识的生成，因此不能只放开输入框就假定整套导入、打包、扩展生态都兼容中文。Java本身并不是完全不支持中文标识符。

原版文件夹错误地复用了相同的工程名限制。本次已拆分为独立文件夹校验：支持中文、空格、数字和 `No.19` 中的点，也支持中文冒号 `：`。仍禁止路径分隔符、ASCII冒号及其他文件保留字符，名称最长100个字符。

教学目录与三个工程的展示名称均为中文，**不需要把文件夹改成拼音**。工程内部标识保留 `YXTeach19Answer`、`YXTeach19Class`、`YXTeach19Starter`，界面中的应用名称仍可为中文。普通上传素材文件名原版还另有资源编译兼容性校验，本次没有一并放开所有资源名。

## 预览更新包

先退出软件，运行 `Yuxuan-Teaching-Preview-for-2.3.3.exe`，选择原有2.3.3安装目录。更新包只更换相应客户端页面资源并加入课程目录和AIA模板，不操作用户工程、授权文件、Python库或Mixly用户数据。

这是供查看教学功能的本地预览补丁，不创建新的公开版本号，也不更改线上更新源。用户工程副本的修改会保留，不会因为切换到教学项目而恢复成模板。

## 开发与重建

1. 将本目录放在现有开发工作区的 `work/teaching-projects` 中，保留已有 App Inventor WSL checkout 和此前的USB、优质扩展等补丁。
2. 在 Ubuntu-24.04 中运行 `prepare.py`，只添加本功能的源码，不从HEAD覆盖已有改动。
3. 在同一环境运行 `compile.py`，增量编译并暂存GWT客户端。
4. 在Windows运行 `catalog.py`，从 `课程大纲.md` 生成目录，打入第19课三份AIA和页面静态资源，并更新缓存版本。
5. `source/`、`patches/` 为可审阅的修改；`source/actions/TeachingProjectsAction.java` 是原生项目导入与编辑桥接。

验证：三个工程从教学界面打开、完整工程APK编译、再次打开保留修改、中文文件夹创建及刷新后保留、8阶段56课目录、空文件夹，以及1600/1440/960/720窗口布局。验证没有使用Android真机。
