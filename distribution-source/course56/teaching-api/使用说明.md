# 第37～42课共用教学服务

这是局域网课堂的示例API，数据均为教学化名和虚构校园地点。需要Python 3.8或以上，无需安装第三方库。不要映射到公网，也不填写真实个人资料。

## 启动

1. 将本文件夹复制到可写位置，保留所有文件。
2. 在羽轩工作台的Python项目中打开本文件夹，运行`teaching_server.py`。默认只供本机访问，浏览器打开`http://127.0.0.1:8765/api/v1/hello`应看到欢迎语。
3. 手机课堂：在该目录打开终端，执行`python teaching_server.py --host 0.0.0.0`。也可双击`启动手机课堂服务.cmd`并选择已安装羽轩工作台内的Python解释器。
4. 将手机和电脑接到同一个教学局域网，选择电脑实际网卡IPv4，在APP的HostBox中只填写该IP，例如`192.168.1.8`，不带协议、端口或路径。服务固定端口8765，首次允许防火墙的专用网络访问。
5. 若电脑能访问、手机不能，检查是否用了虚拟网卡地址、访客Wi-Fi隔离或防火墙。手机的`127.0.0.1`表示手机自身。

关闭终端前按Ctrl+C。数据保存在同目录`teaching-data.json`，下次启动继续使用。需要清空时先关闭服务、备份并重命名此文件。数据损坏时服务拒绝启动，不自动覆盖。

## 教学场景

关闭当前服务后，使用相同命令加参数即可切换：

|参数|现象|
|---|---|
|`--scenario normal`|正常返回，默认值|
|`--scenario delay`|GET延迟6000ms，对照APP的5000ms超时|
|`--scenario error`|GET返回HTTP 500|
|`--scenario empty`|公告与活动为空列表|
|`--scenario invalid-json`|公告接口返回损坏JSON|

以上场景不模拟POST丢失，避免掩盖“超时但服务可能已保存”的情况。提交反馈或留言超时后先查看结果，再决定是否重试。第42课的缓存时间表示APP收到数据的时间，服务示例updatedAt并非实时网络数据。

完整端点和字段见`接口规格.md`。教师可运行`python test_teaching_server.py`，测试使用临时文件和随机端口，不改动课堂数据。程序不是生产级账号或留言系统。
