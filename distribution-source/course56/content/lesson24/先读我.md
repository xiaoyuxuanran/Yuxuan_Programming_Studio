# 第24课｜我的声音工作室

这是一份90分钟课程的教学内容源稿，项目为**录音留言与试听**。

声音留言工具：录制一段留言，停止后试听，并显示录音状态。

## 建议阅读顺序

1. 教师教案：了解本课目标、90分钟安排和答疑。
2. 学生任务单：按支架任务预测、制作、互测。
3. PPT：文字与表格可编辑，逐页教师备注对应本教案。
4. AIA：先发Class版，完成后再对照完整答案。

## 三个工程版本

| 版本 | 内容 |
| --- | --- |
| 完整答案 | YXCourse24.aia：完整参考答案，含本课全部交互。 |
| 课堂支架 | YXCourse24Class.aia：保留全部变量和按钮状态过程、RecordButton、StartedRecording、StopButton、Completed、PermissionDenied、ErrorOccurred、StoppedRecording异常恢复；添加Recorder.AfterSoundRecorded，保存sound并设置AudioPlayer.Source；添加PlayButton.Click，有路径且空闲时启动试听；录第二段后检查播放源已更新。 |
| 纯界面起始版 | YXCourse24Starter.aia：组件、初始属性与素材齐全，没有积木。 |

## 当前内容说明

`content.json` 是PPT与课程包装配的结构化源内容；此目录中的“工程名”描述交付规格，实际AIA/PPT/截图由制作流程装配到最终输出目录。不能据此声称导入、编译或设备运行已经通过。查看最终课程包的验证说明确认验证范围。

导入路径：平台App Inventor → 项目 → 导入项目(.aia)。设计器预览不执行程序；运行需课堂已有Android环境。项目内部名采用英文数字以保持兼容；屏幕上的中文文字不受此限制。
