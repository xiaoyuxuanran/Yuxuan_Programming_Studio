# 第17课｜让角色动起来

**项目：小球运动与图片触摸定位实验　时长：90分钟　配套课件：24页**

## 学习目标与达标证据

1. 区分Speed与Interval，完成运行/暂停时的速度控制。
2. 把四个方向选择映射到0、90、180、270度Heading。
3. 按图片半宽高对齐触点，并限制图片完整位于画布。

## 示例边界

小球在画布中按所选方向与滑块速度运动，开始与暂停切换；静态图片角色按触摸点定位并限制在边界内。恢复起点重置状态与位置。

本课小球到边暂不反弹，反弹在第18课学习。Interval固定50ms，Speed滑块1～8；自动连续移动依赖原生Sprite调度，逻辑测试不能证明真实帧率。

## 核心任务与参考答案

### 任务1：补运行与暂停速度

1. 导入Class版，找到刷新速度过程。
2. 运行中为真时Speed=round(滑块位置)，假时Speed=0。
3. 同步开始/暂停按钮文字，运行后暂停检查位置不再变化。

提问：仅把按钮文字改为暂停，小球会自动停吗？

参考：不会。文字是显示，必须在暂停状态把RunnerBall.Speed设0。

### 任务2：把选择映射到方向

1. 找到DirectionPicker.AfterPicking的占位。
2. 把右、上、左、下分别映射0、90、180、270。
3. 在画布中间恢复起点后，分别试右与上，观察X/Y变化。

提问：向上运动时Y应增加还是减少？

参考：减少，因为屏幕坐标Y向下增大。

### 任务3：完成图片触摸定位

1. 定位图片的目标左上X为触点X-Marker.Width/2，Y同理。
2. 把X限制在0到画布宽减图片宽，Y同理。
3. 点按中间与四角，确认图片完整可见，再测试恢复起点。

提问：为什么右下角触点不能直接作为图片左上位置？

参考：图片会从触点继续向右下延伸并越界；要先中心对齐再限制范围。

## 组件与程序核对

| 名称 | 类型 | 教学作用 |
| --- | --- | --- |
| StageCanvas | Canvas | 角色活动区域 |
| RunnerBall | Ball | 自动运动的小球 |
| Marker | ImageSprite | 触摸定位的图片角色 |
| RunButton | Button | 开始或暂停 |
| DirectionPicker | ListPicker | 选择运动方向 |
| SpeedSlider | Slider | 速度1到8 |
| ResetButton | Button | 恢复起点 |
| StatusLabel | Label | 显示运动参数 |

- 当 `RunButton.Click`：运行中取反；刷新速度；同步按钮文字。
- 当 `DirectionPicker.BeforePicking`：Elements←右、上、左、下。
- 当 `DirectionPicker.AfterPicking`：按SelectionIndex设Heading为0、90、180、270。
- 当 `SpeedSlider.PositionChanged`：刷新速度与状态标签。
- 当 `StageCanvas.Touched`：定位图片(x,y)。
- 当 `ResetButton.Click`：回到起点。

## 过程定义的教学核对

- `刷新速度`：若运行中，RunnerBall.Speed←round(SpeedSlider.ThumbPosition)，否则Speed←0。
- `定位图片(x,y)`：Marker.X←max(0,min(Canvas.Width-Marker.Width,x-Marker.Width/2))；Y同理。
- `回到起点`：运行中false；Ball.MoveTo(30,80)；Speed0；Marker.MoveTo(120,150)。

## 常见问题

| 现象或误解 | 排查提示 |
| --- | --- |
| 按钮写暂停，小球仍走 | 暂停分支需Speed0。 |
| 滑块变化使暂停也开始走 | 刷新速度仍应先检查运行中。 |
| 向上却向下移动 | 核对Heading90与屏幕Y的区别。 |
| 图片只剩一角 | 先减半宽高，再按整个图片尺寸限制边界。 |

## 分层与评价

- **基础：**完成速度、四方向与触摸定位，解释两种坐标含义。
- **提高：**固定Interval，比较两档Speed并记录观察，不把结果声称为严格帧率。
- **拓展：**为图片设计安全停靠区域，先规定可移动范围，再调整边界公式。

建议功能与规则4分、概念解释2分、测试修正2分、工程保存2分。未完成设备运行的项目，运行分保持待评。

## 出口题参考

1. Speed为4、Interval为50，Speed表示每秒4像素吗？
   参考：不是，它表示每次更新的移动距离；Interval是更新间隔。
2. Heading90对应什么方向？
   参考：向上，通常表现为Y减少。
3. 40宽图片要以触点100为中心，未限边时左上X是多少？
   参考：100-20=80。
