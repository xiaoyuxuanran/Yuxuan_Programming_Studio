# 第17课｜让角色动起来

这是一份90分钟课程的教学内容源稿，项目为**小球运动与图片触摸定位实验**。

小球在画布中按所选方向与滑块速度运动，开始与暂停切换；静态图片角色按触摸点定位并限制在边界内。恢复起点重置状态与位置。

## 建议阅读顺序

1. 教师教案：了解本课目标、90分钟安排和答疑。
2. 学生任务单：按支架任务预测、制作、互测。
3. PPT：文字与表格可编辑，逐页教师备注对应本教案。
4. AIA：先发Class版，完成后再对照完整答案。

## 三个工程版本

| 版本 | 内容 |

| 纯界面起始版 | YXCourse17Starter.aia：组件、初始属性与素材齐全，没有积木。 |
