# 第16课｜用程序画出图案

**项目：循环几何图案生成器　时长：90分钟　配套课件：24页**

## 课前准备

本课采用“体验—预测—制作—改编—分享”的节奏。先向学生发课堂支架版，完成后再对照答案。纯界面版用于课后重建，避免90分钟都用于重复搭界面。

| --- | --- |
| 完整答案 | YXCourse16.aia：完整参考答案，含本课全部交互。 |
| 课堂支架 | YXCourse16Class.aia：保留完整按钮入口、画方格的前两条边、横线循环框架，Y暂固定30、单个圆的画圆环过程；横线两个Y改为30+i×30；补齐方格后两条边；用半径20、40、60循环画空心圆。 |
| 纯界面起始版 | YXCourse16Starter.aia：组件、初始属性与素材齐全，没有积木。 |

运行使用教师已配置的Android设备或模拟器；组件设计器不执行点击逻辑。无设备时仍可做积木分析，但任务单的运行结果须写“待测”。

## 学习目标与达标证据

1. 把循环变量代入坐标，解释五条等距横线。
2. 用x、y、边长参数完成一个闭合方格。
3. 用同圆心与不同半径画空心圆，并通过参数改动验证规律。

## 示例边界

按钮分别生成五条间距30的横线、两个同样大小不同位置的方格，以及半径20、40、60的同心空心圆。每种图案先清空旧画面。

Class版已给按钮入口、横线循环框架、方格前两条边和单圆示范。学生补Y表达式、后两条边和半径循环；不需要外部图形素材。

## 核心任务与参考答案

### 任务1：修正五条横线的Y

1. 导入Class版，找到LinesButton.Click里的0～4循环。
2. 把DrawLine两端固定30的Y都改为30+i×30。
3. 点击横线，检查30、60、90、120、150五个位置。

提问：只改起点Y、终点Y仍为30，会出现什么？

参考：后几条线变成斜线；一条横线的两端Y必须相同。

### 任务2：补完整闭合方格

1. 找到画方格(x,y,边长)已有的前两条边。
2. 补第三条到(x,y+边长)，再补第四条回(x,y)。
3. 观察两个调用的位置不同、大小相同；把边长80改为50验证。

提问：只修改一条边的80，为什么不能完整缩小方格？

参考：四条边应共同使用边长参数；写死某条长度会破坏形状一致与闭合。

### 任务3：把单圆变为圆环循环

1. 找到画圆环(中心X,中心Y)。
2. 以半径20到60、步长20循环，DrawCircle使用循环半径。
3. fill设假，检查三个圆心相同，再试改变步长。

提问：fill为真时为什么可能只看见最大的色块？

参考：实心大圆会覆盖内部较小圆的区域；空心圆需要fill为假。

## 组件与程序核对

| 名称 | 类型 | 教学作用 |
| --- | --- | --- |
| PatternCanvas | Canvas | 程序绘图区域 |
| LinesButton | Button | 生成五条横线 |
| GridButton | Button | 绘制方格 |
| RingsButton | Button | 绘制同心圆 |
| ClearButton | Button | 清空图案 |

- 当 `LinesButton.Click`：清空；for each number i从0到4步长1：DrawLine(20,30+i*30,Canvas.Width-20,30+i*30)。
- 当 `GridButton.Click`：清空；画方格(30,30,80)；画方格(130,130,80)。
- 当 `RingsButton.Click`：清空；画圆环(Canvas.Width/2,150)。
- 当 `ClearButton.Click`：清空。

## 过程定义的教学核对

- `画方格(x,y,边长)`：DrawLine四次连接(x,y)、(x+边长,y)、(x+边长,y+边长)、(x,y+边长)。
- `画圆环(中心X,中心Y)`：for each number半径20到60步长20，DrawCircle(中心X,中心Y,半径,false)。

请同时对照上方“三个工程版本”区分已给结构与学生任务，不把完整支架重复布置为缺失内容。

## 常见问题

| 现象或误解 | 排查提示 |
| --- | --- |
| 只看到一条横线 | Y仍固定30，循环画到了同一位置。 |
| 横线变斜线 | 两端Y表达式应相同。 |
| 方格缺口或变形 | 核对四点、参数和回到起点的最后一条边。 |
| 同心圆只剩色块 | 检查fill是否为假。 |

## 分层与评价

- **基础：**完成横线规律、闭合方格和三空心圆。
- **提高：**只改一个参数，生成不同大小或间距的图案并写出预测。
- **拓展：**设计自己的几何纹样，先写坐标规律再用循环绘制；避免无目的复制大量画线调用。

建议功能与规则4分、概念解释2分、测试修正2分、工程保存2分。未完成设备运行的项目，运行分保持待评。

## 出口题参考

1. i从0到4、步长1，共执行几次？
   参考：5次，包括0和4。
2. Y=30+i×30，i为3时Y是多少？
   参考：120。
3. 同心圆的哪些参数相同，哪个参数变化？
   参考：圆心X/Y相同，半径变化。
