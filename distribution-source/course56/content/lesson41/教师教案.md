## 学习目标与达标证据

1. 每台手机有自己的界面和变量。

## 课堂支架与实际程序核对

已给结构：

- 数据变量、完整读取和显示列表
- 双按钮入口、详情与故障恢复
- GotText仅支持读取200；发布留言占位

学生要补或修正：

- 发布留言校验昵称1～12和正文1～120并编码表单
- GotText按操作区分发布201和读取200
- 201有id才清稿，再Get刷新；绝不再次Post自动重发

实际全局变量：`请求中`、`当前URL`、`操作`、`留言`、`显示留言`、`响应数据`。

### 过程职责（教师参考）

- `读取留言`：操作读取；Url←/api/v1/messages；Get；禁用请求。
- `发布留言`：校验昵称正文；操作发布；设置表单头；PostText(BuildRequestData(nick,message))。
- `显示留言`：items保存到留言；显示昵称+正文摘要；清旧选择。

### 三组真实积木截图

1. `读取留言`：读取已给，发布过程待补；两按钮在请求中都禁用。
2. `Http.GotText`：按操作区分201与200，发布确认后读取，不自动再次Post。
3. `MessagesView.AfterPicking`：详情入口已给，使用同序索引和完整字典字段。

### 设备与验证边界

使用随课Python课堂服务，HostBox只填电脑局域网IPv4。示例不是公网服务；手机上的127.0.0.1指手机自身。服务的自动测试不等于Android客户端真机联调。 同一课堂服务共享最近50条留言。仅用课堂昵称，示例没有账号、权限或公开审核系统。

- 教师电脑运行配套Python标准库API，手机与电脑在可互通的同一局域网。
- 电脑本机可用127.0.0.1；手机必须填写教师电脑局域网IPv4，不能填127.0.0.1。
- HTTP用于隔离的课堂教学数据，不填写真实个人资料；Android明文HTTP兼容性以本平台打包结果实测。

### 共用课堂服务

教师使用随课 `teaching-api/teaching_server.py`；Python 3.8或3.13均可，无需第三方库。先在电脑浏览器核对欢迎接口。手机课堂运行 `python teaching_server.py --host 0.0.0.0`，使用电脑实际局域网IPv4。HostBox仅填IP，例如192.168.1.8；工程初值192.168.1.10是示例，不是固定地址。不要填协议、端口或路径；端口8765和接口路径由积木拼接。手机与电脑需在可互通的教学局域网，手机的127.0.0.1表示手机自身。

可重复故障：先停止当前服务，再加 `--scenario delay`（GET延迟6秒，对照APP超时5秒）、`error`（GET 500）、`empty`（空公告/活动）、`invalid-json`（坏JSON）。恢复用 `--scenario normal`。普通AIA按钮即可触发，不改HostBox为路径，也无需物理断网。POST超时不自动重发；先查结果再决定是否重试。示例仅教学数据，无账号权限系统，勿作为生产留言平台。

## 核心任务与参考答案

### 任务1：阅读公共读取并补发布

1. 保留已给读取留言过程。
2. 发布昵称trim后1到12字符，正文1到120字符。
3. 设置操作发布、禁用两键，编码nick和message后PostText。

提问：两台手机为什么必须填同一个电脑地址？

参考：共同访问同一个服务才能读取同一份留言数据。

### 任务2：补发布响应分支

1. GotText先看操作与状态码。
2. 发布201且id有效才清正文。
3. 结束该发布状态，再调用读取留言Get刷新。
4. 读取200才解析items；失败保留草稿。

提问：发布后刷新会不会再次发布？

参考：不会，刷新走Get；不能再次调用发布留言过程。

### 任务3：互测摘要与详情

1. 阅读已给MessagesView.AfterPicking。
2. 按索引显示nick、完整message、id、createdAt。
3. 课堂两端一端发、一端刷新，对比同一id。
4. 说明50条保留政策和服务时间来源。

提问：列表摘要被截短是否代表正文丢失？

参考：不代表，完整正文仍在字典中，详情应读原字段。

## 组件与程序核对

| 名称 | 类型 | 教学作用 |
| --- | --- | --- |
| HostBox | TextBox | 教师电脑局域网IPv4地址 |
| RequestButton | Button | 发起本课请求 |
| StatusLabel | Label | 请求与错误状态 |
| NickBox | TextBox | 课堂昵称 |
| MessageBox | TextBox | 留言内容 |
| PostButton | Button | 发布留言 |
| MessagesView | ListView | 共享留言 |
| DetailLabel | Label | 所选留言详情 |
| Http | Web | 教学HTTP客户端 |

- 当 `RequestButton.Click`：读取留言。
- 当 `PostButton.Click`：发布留言。
- 当 `Http.GotText`：发布201则清正文后读取留言；读取200则显示留言并恢复按钮；错误恢复但不清稿。
- 当 `MessagesView.AfterPicking`：取对应字典显示nick,message,id,createdAt。
- 当 `Http.TimedOut`：恢复按钮，说明状态未确认。
