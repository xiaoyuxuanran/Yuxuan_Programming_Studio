# 第41课｜多个用户共享信息

这是一份90分钟课程的教学内容源稿，项目为**共享留言GET/POST与发布后自动刷新**。

课堂留言墙：两台客户端向同一服务写留言，刷新后都能看到公共列表。

## 建议阅读顺序

1. 教师教案：了解本课目标、90分钟安排和答疑。
2. 学生任务单：按支架任务预测、制作、互测。
3. PPT：文字与表格可编辑，逐页教师备注对应本教案。
4. AIA：先发Class版，完成后再对照完整答案。

## 三个工程版本

| 版本 | 内容 |
| --- | --- |
| 完整答案 | YXCourse41.aia：完整参考答案，含本课全部交互。 |
| 课堂支架 | YXCourse41Class.aia：保留数据变量、完整读取和显示列表、双按钮入口、详情与故障恢复、GotText仅支持读取200；发布留言占位；发布留言校验昵称1～12和正文1～120并编码表单；GotText按操作区分发布201和读取200；201有id才清稿，再Get刷新；绝不再次Post自动重发。 |
| 纯界面起始版 | YXCourse41Starter.aia：组件、初始属性与素材齐全，没有积木。 |
