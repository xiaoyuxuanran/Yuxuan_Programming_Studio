# 第5课｜给 APP 设计漂亮的界面

**项目：校园创意节信息页　时长：90分钟　配套课件：24页**

## 课前准备

本课采用“体验—预测—制作—改编—分享”的节奏。先向学生发课堂支架版，完成后再对照答案。纯界面版用于课后重建，避免90分钟都用于重复搭界面。

| 版本 | 内容 |
| --- | --- |
| 完整答案 | Course05Festival.aia：完整参考答案，含本课全部交互。 |
| 课堂支架 | Course05FestivalClass.aia：保留TimeButton.Click；补齐 PlaceButton.Click 与 SignupButton.Click；补齐 ResetButton.Click 并检查标题、正文、提示的层级。 |
| 纯界面起始版 | Course05FestivalStarter.aia：组件、初始属性与素材齐全，没有积木。 |

运行使用教师已配置的Android设备或模拟器；组件设计器不执行点击逻辑。无设备时仍可做积木分析，但任务单的运行结果须写“待测”。

## 学习目标与达标证据

1. 用水平与垂直布局组织标题、导航和正文，解释层级关系。
2. 让分类按钮同步更新InfoTitle与InfoLabel。
3. 以找得到、看得清、点得准评价界面，并修正一种真实问题。

## 示例边界

虚构校园创意节的信息页。时间、地点、报名三个按钮在同一行，点击后更新信息标题与正文，活动首页恢复欢迎内容。

报名仅展示课堂说明，不提交数据、不收集个人信息。界面练习使用现有事件，不新增变量、网页或登录。美观评价以可读与可操作为依据。

## 核心任务与参考答案

### 任务1：用组件树读布局

1. 导入Course05FestivalClass.aia，依次展开Page、HeroRow、MenuRow和InfoCard。
2. 找到三个分类按钮，查看Width的百分比设置。
3. 用纸笔画出标题、导航、正文和提示的阅读顺序。

提问：把三个按钮放入垂直布局，阅读顺序会怎样变化？

参考：按钮会由上下排列；水平布局让同级导航并排。选择哪种取决于屏幕宽度和按钮文字长度。

### 任务2：补全地点与报名说明

1. 读取已给出的TimeButton.Click，找出两个属性设置。
2. 补PlaceButton.Click，同时设置InfoTitle为活动地点、InfoLabel为示例地点说明。
3. 补SignupButton.Click，同时更新标题与报名说明，明确没有真实提交。

提问：只修改正文却不改InfoTitle，会有什么问题？

参考：标题仍显示上一个分类，用户可能误读信息。分类标题与正文需要同步。

### 任务3：恢复首页并做可用性修改

1. 补ResetButton.Click，把InfoTitle与InfoLabel恢复初始欢迎内容。
2. 请同伴不听说明找到时间、地点和报名方式，记录卡住的位置。
3. 修改字号、留白或按钮文字中的一项；分别试长正文与较窄屏幕，再导出AIA。

提问：文字被截住时，为什么不应马上把字号缩得很小？

参考：小字可能难读。先检查容器宽高、自动高度和滚动，再决定合适字号；内容完整和可读都要兼顾。

## 组件与程序核对

| 名称 | 类型 | 教学作用 |
| --- | --- | --- |
| HeroRow | HorizontalArrangement | 图标与主题语并排 |
| MenuRow | HorizontalArrangement | 排列三项分类 |
| InfoCard | VerticalArrangement | 组织标题与正文 |
| InfoTitle | Label | 说明当前分类 |
| InfoLabel | Label | 展示对应信息 |
| TimeButton | Button | 时间 |
| PlaceButton | Button | 地点 |
| SignupButton | Button | 报名说明 |
| ResetButton | Button | 恢复活动首页 |

- 当 `TimeButton.Click`：InfoTitle.Text ← 活动时间；InfoLabel.Text ← 示例时间：周五 15:00—16:30。
先到展示区集合，再参加同伴体验。。
- 当 `PlaceButton.Click`：InfoTitle.Text ← 活动地点；InfoLabel.Text ← 示例地点：学校创意教室。
从教学楼一层入口进入，按现场指引到作品展示区。。
- 当 `SignupButton.Click`：InfoTitle.Text ← 报名方式；InfoLabel.Text ← 课堂演示：向老师说明作品名称与展示方式。
此按钮仅显示报名说明，不会提交任何资料。。
- 当 `ResetButton.Click`：InfoTitle.Text ← 欢迎参加创意节；InfoLabel.Text ← 展示游戏、故事和生活小工具。点击上方的分类，查看活动信息。。

## 常见问题

| 现象或误解 | 排查提示 |
| --- | --- |
| 导航按钮挤成一列 | 检查MenuRow是否为HorizontalArrangement，三个按钮是否放在其中。 |
| 标题与正文不一致 | 每个分类事件都同步设置InfoTitle与InfoLabel。 |
| 长文字被截断 | 检查标签高度、父容器和页面滚动，别只缩小字号。 |
| 颜色多但重点不清楚 | 保留蓝白主色，用字号、粗细和间距区分层级。 |

## 分层与评价

- **基础：**完成三个分类和首页事件，同步显示标题与正文。
- **提高：**根据同伴反馈调整一项布局，并用前后证据说明改善。
- **拓展：**增加交通或作品须知分类；先检查窄屏导航是否仍可读，再决定换行或调整结构。

建议功能与规则4分、概念解释2分、测试修正2分、工程保存2分。未完成设备运行的项目，运行分保持待评。

## 出口题参考

1. HeroRow和InfoCard为什么使用不同布局？
   参考：前者让图标和标语并排；后者让标题和正文上下阅读。
2. 地点按钮里至少需要更新哪两个组件？
   参考：InfoTitle与InfoLabel。
3. 怎样证明界面比修改前更好用？
   参考：给同伴同一项查找任务，比较完成情况和具体卡点；同时检查窄屏与长文本。
