## 课堂支架与实际程序核对

已给结构：

- 请求状态与当前URL
- 结束请求和两个按钮入口
- 请求文本地址组合占位、GotText占位

学生要补或修正：

- 请求文本加入请求中状态、禁用按钮和Get
- GotText按200/其他状态处理并结束请求
- 添加TimedOut与ErrorOccurred恢复

实际全局变量：`请求中`、`当前URL`。

### 过程职责（教师参考）

- `请求文本(路径)`：若非请求中且Host非空：请求中true；禁用两个请求按钮；Url←http://Host:8765+路径；Get。
- `结束请求(提示)`：请求中false；恢复按钮；显示提示。

### 三组真实积木截图

1. `请求文本`：保留路径参数，HostBox不填协议或端口。请求前更新状态。
2. `Http.GotText`：当前URL核对避免把其他响应当成本次结果；这里只显示文本。
3. `Http.TimedOut`：超时是异步事件，应恢复按钮并给出可操作提示。

### 设备与验证边界

使用随课Python课堂服务，HostBox只填电脑局域网IPv4。示例不是公网服务；手机上的127.0.0.1指手机自身。服务的自动测试不等于Android客户端真机联调。 本课读取纯文本，不解码JSON；HTTP 404仍属于收到服务器响应。

- 教师电脑运行配套Python标准库API，手机与电脑在可互通的同一局域网。
- 电脑本机可用127.0.0.1；手机必须填写教师电脑局域网IPv4，不能填127.0.0.1。
- HTTP用于隔离的课堂教学数据，不填写真实个人资料；Android明文HTTP兼容性以本平台打包结果实测。

### 共用课堂服务

教师使用随课 `teaching-api/teaching_server.py`；Python 3.8或3.13均可，无需第三方库。先在电脑浏览器核对欢迎接口。手机课堂运行 `python teaching_server.py --host 0.0.0.0`，使用电脑实际局域网IPv4。HostBox仅填IP，例如192.168.1.8；工程初值192.168.1.10是示例，不是固定地址。不要填协议、端口或路径；端口8765和接口路径由积木拼接。手机与电脑需在可互通的教学局域网，手机的127.0.0.1表示手机自身。

可重复故障：先停止当前服务，再加 `--scenario delay`（GET延迟6秒，对照APP超时5秒）、`error`（GET 500）、`empty`（空公告/活动）、`invalid-json`（坏JSON）。恢复用 `--scenario normal`。普通AIA按钮即可触发，不改HostBox为路径，也无需物理断网。POST超时不自动重发；先查结果再决定是否重试。示例仅教学数据，无账号权限系统，勿作为生产留言平台。

## 核心任务与参考答案

### 任务1：补请求过程

1. 找到请求文本过程，保留已有URL拼接。
2. 请求中真，禁用两个请求按钮。
3. 设置Http.Url为当前URL并调用Get。
4. 连续点击不重复发送。

提问：Get返回时已经拿到文本了吗？

参考：没有，结果通过稍后的GotText或TimedOut事件到达。

### 任务2：补文本回调

1. 添加Http.GotText，只处理当前请求URL。
2. responseCode=200才显示responseContent。
3. 其他码显示HTTP编号，不把错误页当问候。
4. 最后调用结束请求恢复按钮。

提问：404与超时有什么不同？

参考：404有HTTP响应但路径不存在；超时是在指定等待时间内未完成请求。

### 任务3：补超时与异常恢复

1. 添加Http.TimedOut并核对url。
2. Screen1.ErrorOccurred也恢复请求状态。
3. 用服务delay场景产生受控延迟，恢复normal后再请求。
4. 不需要物理断网来做此课堂实验。

提问：为什么异常分支也要启用按钮？

参考：否则界面会一直停在请求中，用户无法纠正地址或重新请求。

## 组件与程序核对

| 名称 | 类型 | 教学作用 |
| --- | --- | --- |
| HostBox | TextBox | 教师电脑局域网IPv4地址 |
| RequestButton | Button | 发起本课请求 |
| StatusLabel | Label | 请求与错误状态 |
| ResultLabel | Label | 显示服务返回的问候 |
| ErrorButton | Button | 请求一个不存在路径 |
| Http | Web | 教学HTTP客户端 |

- 当 `RequestButton.Click`：请求文本(/api/v1/hello)。
- 当 `ErrorButton.Click`：请求文本(/api/v1/missing)。
- 当 `Http.GotText`：responseCode=200时ResultLabel←responseContent，否则显示HTTP状态码；结束请求。
- 当 `Http.TimedOut`：结束请求(请求超时，请检查地址与服务)。
- 当 `Screen1.ErrorOccurred`：结束请求(显示通信错误)。

## 出口题参考

1. 手机里localhost指哪台设备？
   参考：指手机自己，不能代替电脑服务地址。
2. 200与404分别说明什么？
   参考：200成功返回；404是服务器找不到请求路径。
3. 请求中标志何时恢复？
   参考：成功、HTTP错误、超时及通信异常的结束路径都要恢复。
