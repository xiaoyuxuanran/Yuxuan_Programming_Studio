# 第37课｜APP 如何访问网络

这是一份90分钟课程的教学内容源稿，项目为**本地HTTP文本问候与404恢复**。

网络问候器：向教师电脑请求一条文本，观察成功、404和超时三种反馈。

## 建议阅读顺序

1. 教师教案：了解本课目标、90分钟安排和答疑。
2. 学生任务单：按支架任务预测、制作、互测。
3. PPT：文字与表格可编辑，逐页教师备注对应本教案。
4. AIA：先发Class版，完成后再对照完整答案。

## 三个工程版本

| 版本 | 内容 |
| --- | --- |
| 完整答案 | YXCourse37.aia：完整参考答案，含本课全部交互。 |
| 课堂支架 | YXCourse37Class.aia：保留请求状态与当前URL、结束请求和两个按钮入口、请求文本地址组合占位、GotText占位；请求文本加入请求中状态、禁用按钮和Get；GotText按200/其他状态处理并结束请求；添加TimedOut与ErrorOccurred恢复。 |
| 纯界面起始版 | YXCourse37Starter.aia：组件、初始属性与素材齐全，没有积木。 |
