## 示例边界

桌面灯控观察台：可靠TCP控制LED亮度，读取旋钮与按钮，保存设备地址并显示最近确认状态。

配套固件及接线表见firmware。参考板为原始ESP32-WROOM DevKit；LED GPIO23串330Ω，ADC1 GPIO34只接0～3.3V电位器滑端，GPIO27按钮接地，0为按下。工程导入、APK编译和桌面协议测试不能代替Android与ESP32实物联调；本次未做真机测试。 复用49课序号协议。只有有效STATE更新ADC相对百分比及最近确认时间；超过10秒标旧数据。IP仅在成功连接后保存，重开恢复地址但不自动认为已连接。

## 核心任务与参考答案

### 任务1：补完整状态面板

1. 处理载荷为本课缺口，其余可靠通信已给。
2. 验证五字段后再更新LED、PWM、ADC和按钮。
3. ADC百分比round(adc/4095×100)，按钮0为按下。
4. 只有有效STATE保存最近确认时刻。

提问：ADC百分比能叫准确湿度吗？

参考：不能，只是旋钮相对读数，没有湿度传感器和校准。

### 任务2：阅读资料年龄检查

1. PollClock.Timer已给，追踪SystemTime减最近确认。
2. 超过10000ms时标记旧数据。
3. 旧数值可以保留，但不称作正在实时更新。

提问：收到一个开灯OK能代替新STATE刷新全部传感器吗？

参考：不能，OK只确认对应命令，不含新的ADC或按钮测量。

### 任务3：核对重开与交付说明

1. Initialize已给，只GetValue lastHost。
2. 确认已连接初值假，未自动恢复上次通道。
3. 教师测试成功连接、PWM128、GET与重开；未实测项目写待测。
4. 提交接线表、协议说明和正常/错误测试记录。

提问：为什么不能把已连接真保存到TinyDB？

参考：连接是当前运行中的实际通道，历史布尔值不能证明现在已连接。

## 组件与程序核对

| 名称 | 类型 | 教学作用 |
| --- | --- | --- |
| HostBox | TextBox | 设备地址 |
| ConnectButton | Button | 连接 |
| DisconnectButton | Button | 断开 |
| BrightnessSlider | Slider | 目标亮度 |
| ApplyButton | Button | 应用 |
| ReadButton | Button | 更新状态 |
| FreshLabel | Label | 最近确认时间和过时状态 |
| Socket | ClientSocketAI2Ext | 可靠TCP |
| LocalDB | TinyDB | 保存地址 |
| PollClock | Clock | 轮询连接状态并检查资料年龄 |

- 当 `Screen1.Initialize`：读取lastHost，已连接设假，提示主动连接并GET。
- 当 `ConnectButton.Click`：保存地址；Connect。
- 当 `ApplyButton.Click`：发送可靠命令(PWM,+round滑块值)。
- 当 `ReadButton.Click`：发送可靠命令(GET)。
- 当 `Socket.DataReceived`：v2组帧；匹配STATE后显示STATE。
- 当 `DisconnectButton.Click`：关闭连接并清等待，不抹掉最后确认数据但标注非实时。
- 当 `PollClock.Timer`：轮询ConnectionState；最近确认超过10秒则标旧数据。

## 出口题参考

1. 资料年龄从何时开始计算？
   参考：最后一次收到并校验有效STATE的本机接收时刻。
2. 重开恢复了什么？
   参考：上次成功连接的IP，不恢复有效连接状态。
3. 10秒后旧值必须清空吗？
   参考：可以保留，但需明确标旧数据并提示重新GET。
