# 第25课｜拍照与图片创作

**项目：本机照片与文字介绍卡　时长：90分钟　配套课件：24页**

本课采用“体验—预测—制作—改编—分享”的节奏。先向学生发课堂支架版，完成后再对照答案。纯界面版用于课后重建，避免90分钟都用于重复搭界面。

## 学习目标与达标证据

1. 相机结果在AfterPicture到达。
2. 只有非空结果才替换现有图片。
3. 用测试记录验证拍照与图片创作的核心规则。

## 示例边界

照片介绍卡：拍摄或选择一张照片，填写标题与说明，生成可阅读的介绍页。

本课在本机显示照片和文字，不上传。启动相机或选择器时保留旧作品；取消可能没有成功回调，不能靠等待回调锁定界面。实际URI和权限需设备验证。

## 课堂支架与实际程序核对

已给结构：

- global 图片路径
- 显示图片、清空卡片
- 相机启动、重置及权限/异常反馈

学生要补或修正：

- 添加Camera1.AfterPicture，使用image回调路径
- 添加PhotoPicker.AfterPicking，复用显示图片
- 添加ApplyButton.Click，校验非空标题并拼接说明

实际全局变量：`图片路径`。

### 过程职责（教师参考）

- `显示图片(路径)`：若路径非空：图片路径←路径；PhotoImage.Picture←路径；显示已选择照片。
- `清空卡片`：路径空；Picture空；标题说明和输出清空。

### 三组真实积木截图

1. `Camera1.AfterPicture`：只在AfterPicture里使用image。Class已给TakePicture入口，不要求再添加重复事件。
2. `PhotoPicker.AfterPicking`：显示图片为共用过程；空Selection不更新。系统URI不应手工改成电脑路径。
3. `ApplyButton.Click`：标题提示写StatusLabel；有效输出写CardLabel。权限与异常反馈保留旧作，取消不是成功拍摄。

### 设备与验证边界

本课在本机显示照片和文字，不上传。启动相机或选择器时保留旧作品；取消可能没有成功回调，不能靠等待回调锁定界面。实际URI和权限需设备验证。

- Android相机和图片选择器；只使用自己有权展示的照片。

## 核心任务与参考答案

### 任务1：补相机结果事件

1. Class已给相机启动、显示图片和清空卡片。
2. 添加Camera1.AfterPicture。
3. 把事件参数image传入显示图片，不提前猜测文件路径。

提问：为什么TakePicture后不能立即显示本次结果？

参考：拍摄在外部界面进行，新的image要等AfterPicture回调。

### 任务2：相册复用显示过程

1. 添加PhotoPicker.AfterPicking。
2. 将PhotoPicker.Selection传给显示图片。
3. 已有照片时打开相册后取消，检查旧图不被擦除。
4. 对照显示图片内非空路径保护。

提问：取消为什么不等于清空？

参考：取消没有新的有效选择；只有非空结果替换旧图，清空由单独按钮执行。

### 任务3：补标题校验和介绍卡

1. 添加ApplyButton.Click，trim标题为空时只在StatusLabel提示。
2. 有效时把标题、换行和说明连接到CardLabel。
3. 生成后取消拍照，确认现有作品仍可使用。
4. 重置后检查图、标题、说明和输出都已清空。

提问：只清空CardLabel能叫清空作品吗？

参考：不能，还要清图片路径、Picture、TitleBox和CaptionBox，避免旧素材残留。

## 组件与程序核对

| 名称 | 类型 | 教学作用 |
| --- | --- | --- |
| PhotoImage | Image | 显示当前照片 |
| CameraButton | Button | 打开相机 |
| PhotoPicker | ImagePicker | 从相册选图 |
| TitleBox | TextBox | 照片标题 |
| CaptionBox | TextBox | 说明 |
| ApplyButton | Button | 生成介绍卡 |
| CardLabel | Label | 显示标题与说明 |
| ResetButton | Button | 清空作品 |
| Camera1 | Camera | 调用手机相机 |
| StatusLabel | Label | 操作、权限和输入校验反馈 |

- 当 `CameraButton.Click`：Camera1.TakePicture。
- 当 `Camera1.AfterPicture`：显示图片(image)。
- 当 `PhotoPicker.AfterPicking`：显示图片(PhotoPicker.Selection)。
- 当 `ApplyButton.Click`：trim标题为空时StatusLabel提示请先输入照片标题；否则CardLabel←去空格标题+换行+去空格说明。
- 当 `ResetButton.Click`：清空卡片。
- 当 `Screen1.PermissionDenied`：提示相机权限被拒绝，可改用相册。
- 当 `Screen1.ErrorOccurred`：显示错误提示，保留已有照片与卡片，不把异常当作清空。

## 出口题参考

1. 相机和相册为什么能共用一个过程？
   参考：两者最终都提供图片引用，显示图片处理共同的非空检查和Picture赋值。
2. 空标题时改写CardLabel会有什么问题？
   参考：可能擦掉已有作品；本工程在StatusLabel提示并保留原卡片。
3. 取消相机没回调，界面如何继续用？
   参考：启动时不清旧图且不锁界面，原作品和其他操作仍可用。
