# 第13课｜把常用功能封装起来

**项目：带参数和返回值的出行预算器　时长：90分钟　配套课件：24页**

## 课前准备

本课采用“体验—预测—制作—改编—分享”的节奏。先向学生发课堂支架版，完成后再对照答案。纯界面版用于课后重建，避免90分钟都用于重复搭界面。

| 版本 | 内容 |
| --- | --- |
| 完整答案 | YXCourse13.aia：完整参考答案，含本课全部交互。 |
| 课堂支架 | YXCourse13Class.aia：保留global 总费用、输入合法性检查、重置过程和两个按钮入口、总交通费与提示的过程框架及占位值；提示过程使用参数内容代替固定文字；总交通费返回人数×单价，替换返回值0；观察CalculateButton如何接入返回值；ResetButton复用重置。 |
| 纯界面起始版 | YXCourse13Starter.aia：组件、初始属性与素材齐全，没有积木。 |

运行使用教师已配置的Android设备或模拟器；组件设计器不执行点击逻辑。无设备时仍可做积木分析，但任务单的运行结果须写“待测”。

## 学习目标与达标证据

1. 用提示(内容)让同一过程显示不同文字。
2. 完成总交通费(人数,单价)的数值返回，解释定义与调用。
3. 追踪两个按钮如何复用已有过程，检查有效、无效和重置。

## 示例边界

输入正整数人数与非负每人交通费，调用返回值过程求乘积，再通过带参数的提示过程显示总交通费；重置清输入与结果。

Class版已给合法性检查、计算入口、重置过程与调用。故意把总交通费过程返回值留为0、提示过程写成固定占位文案，学生替换这两处；这是课堂算例，不涉及真实报价或付款。

## 核心任务与参考答案

### 任务1：让提示使用传入的内容

1. 导入Class版，找到提示(内容)定义。
2. 将固定占位文字替换为读取参数内容。
3. 用合法和非法输入分别点击计算，检查提示不再总是一句话。

提问：定义了参数却不用它，会发生什么？

参考：调用者传不同数据也不会影响过程动作，若内部仍写固定文字，所有调用就显示同一句。

### 任务2：返回正确总交通费

1. 找到总交通费(人数,单价)的有返回值定义。
2. 把返回0替换为人数×单价。
3. 追踪CalculateButton如何把返回数值存入总费用，再连接元的提示。

提问：人数和单价参数必须从全局变量读取吗？

参考：不需要，它们是这次调用传入的局部参数，在所属过程内部直接读取；同一定义可处理不同输入。

### 任务3：追踪已有重置并作回归测试

1. 找到ResetButton.Click对重置过程的调用。
2. 读重置：清两输入、总费用归0、调用提示恢复说明。
3. 计算3人12.5元、重置，再计算1人0元；另测0人和2.5人。

提问：Class版已经给重置调用，本课还要复制一套清空代码吗？

参考：不用。重点是读懂复用关系，确认一个定义服务于入口，而不是无意义复制。

## 组件与程序核对

| 名称 | 类型 | 教学作用 |
| --- | --- | --- |
| PeopleBox | TextBox | 输入人数 |
| FeeBox | TextBox | 每人费用 |
| CalculateButton | Button | 计算预算 |
| ResultLabel | Label | 显示结果 |
| ResetButton | Button | 重置 |

- 当 `CalculateButton.Click`：验证人数正整数且费用非负；总费用=总交通费(人数,费用)；提示连接结果与元；无效调用提示错误。
- 当 `ResetButton.Click`：重置。

## 过程定义的教学核对

- `总交通费(人数,单价)`：有返回值：人数×单价。
- `提示(内容)`：ResultLabel.Text=内容。
- `重置`：清两个输入；总费用=0；提示('请输入人数与单价')。

## 常见问题

| 现象或误解 | 排查提示 |
| --- | --- |
| 每种输入都出现同一句 | 提示内部仍写死占位文字，未读取参数内容。 |
| 总费用始终为0 | 返回值仍是Class版占位0。 |
| 过程接不进数值输入槽 | 确认选择有返回值的总交通费过程。 |
| 在过程外直接找不到参数 | 参数的使用范围属于定义它的过程。 |

## 分层与评价

- **基础：**补提示参数与乘积返回，解释定义、调用、参数、返回。
- **提高：**把提示格式改为人数×单价=总费用，保持计算过程不变。
- **拓展：**增加门票小计过程，并在调用处合并预算；先定义每个返回值的含义。

建议功能与规则4分、概念解释2分、测试修正2分、工程保存2分。未完成设备运行的项目，运行分保持待评。

## 出口题参考

1. 总交通费(3,12.5)应返回什么？
   参考：37.5这个数值。
2. 提示过程为什么适合无返回值？
   参考：它负责更新标签的动作，调用者不需要再取得一个数据结果。
3. 只修改一次提示定义，为什么多处反馈都能改变？
   参考：多个入口都调用同一定义；每次传入自己的内容，由该定义完成显示。
