# 第3课｜会发声的伙伴

**项目：伙伴声音盒　时长：90分钟　配套课件：24页**

## 课前准备

本课采用“体验—预测—制作—改编—分享”的节奏。先向学生发课堂支架版，完成后再对照答案。纯界面版用于课后重建，避免90分钟都用于重复搭界面。

| 版本 | 内容 |
| --- | --- |
| 完整答案 | Course03Voice.aia：Cat、Dog、Stop三组事件完整，带feedback.wav本地短提示音。 |
| 课堂支架 | Course03VoiceClass.aia：组件、素材与CatButton.Click示范已给出；学生完成DogButton.Click和StopButton.Click。 |
| 纯界面起始版 | Course03VoiceStarter.aia：相同界面、非可视组件及短音资源，积木为空。 |

运行使用教师已配置的Android设备或模拟器；组件设计器不执行点击逻辑。无设备时仍可做积木分析，但任务单的运行结果须写“待测”。

若当前屏幕需滚动才能看到停止按钮，可先滚动找到它；具体设备布局在运行时另验。

## 学习目标与达标证据

1. 区分设置属性与调用方法：文字显示用Text，发声用Speak/Play。
2. 参照小猫事件完成小狗事件，并能同时停止语音和短提示音。
3. 记录声音资源路径、语音引擎前提与实际听觉测试结果。

## 示例边界

小猫或小狗按钮先停止上一段语音，播放本地操作提示音feedback.wav，更新StatusLabel并调用PetSpeech.Speak进行中文自我介绍；停止按钮同时停止语音与短音并显示停止提示。

本课的动物介绍由TextToSpeech合成，不是动物录音；feedback.wav是独立的短提示音。中文朗读依赖设备已安装并可用的中文TTS引擎，不能由AIA编译成功推断声音可听。可选真实动物音频需教师提前准备自录或有许可的文件。

## 核心任务与参考答案

### 任务1：找到两种声音来源

1. 导入Course03VoiceClass.aia，选择非可视组件PetSpeech与FeedbackSound。
2. 检查FeedbackSound.Source为feedback.wav，媒体区有同名文件。
3. 确认教师测试环境中的中文语音引擎可用，媒体音量适中。

提问：feedback.wav和Speak输入的文字是同一种资源吗？

参考：不是；Sound播放已有音频文件，TextToSpeech把文字交给设备语音引擎合成。

### 任务2：参照小猫制作小狗

1. 阅读已提供的CatButton.Click，指出Stop、Play、标签设置和Speak。
2. 添加DogButton.Click：先PetSpeech.Stop，再FeedbackSound.Play。
3. 设置StatusLabel.Text为“小狗：我是小狗，汪汪汪。”，调用PetSpeech.Speak并传入“我是小狗，汪汪汪”。

提问：为什么改了StatusLabel.Text，还不能保证听到声音？

参考：标签只负责显示，声音需要Speak调用以及可工作的设备语音引擎与音量设置。

### 任务3：停止发声并互测

1. 添加StopButton.Click，依次调用PetSpeech.Stop和FeedbackSound.Stop。
2. 把StatusLabel.Text设为“声音已停止，再选一个伙伴吧。”。
3. 依次测试小猫→停止→小狗；避免多人同时高音量播放，再导出AIA。

提问：为什么停止按钮不只改成“已经停止”的文字？

参考：文字反馈不等于停止声音，必须调用对应声音组件的停止方法。

## 组件与程序核对

| 名称 | 类型 | 教学作用 |
| --- | --- | --- |
| StatusLabel | Label | 显示当前伙伴及停止反馈 |
| CatButton | Button | 小猫语音介绍 |
| DogButton | Button | 小狗语音介绍 |
| StopButton | Button | 停止发声 |
| PetSpeech | TextToSpeech | 把中文文字交给设备语音引擎朗读 |
| FeedbackSound | Sound | 播放工程中的短操作提示音feedback.wav |

- 当 `CatButton.Click`：调用PetSpeech.Stop；调用FeedbackSound.Play；StatusLabel.Text ← 小猫：我是小猫，喵喵喵。；调用PetSpeech.Speak，message=我是小猫，喵喵喵。
- 当 `DogButton.Click`：调用PetSpeech.Stop；调用FeedbackSound.Play；StatusLabel.Text ← 小狗：我是小狗，汪汪汪。；调用PetSpeech.Speak，message=我是小狗，汪汪汪。
- 当 `StopButton.Click`：调用PetSpeech.Stop；调用FeedbackSound.Stop；StatusLabel.Text ← 声音已停止，再选一个伙伴吧。。

## 常见问题

| 现象或误解 | 排查提示 |
| --- | --- |
| 标签更新了，所以声音一定正常 | 标签与声音是两个证据；逐项记录短音、语音、停止效果。 |
| 没有语音就反复拖Speak积木 | 先检查设备TTS引擎/中文语言包和媒体音量，再检查message输入及事件连接。 |
| Source填写电脑绝对路径 | 打包素材使用工程媒体中的feedback.wav；另一台设备不能读取教师电脑路径。 |
| 用Sound播放很长背景音乐 | 较长音频可选Player；本课只用Sound短音，不包含Player组件。 |

## 分层与评价

- **基础：**完成Dog与Stop，准确解释显示和发声是不同动作。
- **提高：**把语音改成一种原创伙伴的简短介绍，保持屏幕文字和朗读内容一致。
- **拓展：**经教师确认许可后导入一段短录音，另建Sound播放；记录素材来源，不将提示音标成动物录音。

建议功能与规则4分、概念解释2分、测试修正2分、工程保存2分。未完成设备运行的项目，运行分保持待评。

## 出口题参考

1. 设置StatusLabel.Text与调用PetSpeech.Speak有什么区别？
   参考：前者改变屏幕文字属性，后者请求语音引擎朗读文字。
2. 停止按钮应调用哪两个方法？
   参考：PetSpeech.Stop和FeedbackSound.Stop。
3. APK编译成功，能否证明每台设备一定能中文朗读？
   参考：不能，还需设备中文TTS引擎、媒体音量等条件，并做实际声音测试。
