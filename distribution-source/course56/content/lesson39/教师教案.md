## 课堂支架与实际程序核对

已给结构：

- 请求响应解码与items类型验证
- 显示地点结果主体列表生成
- 结束请求和错误恢复；查询与详情占位

学生要补或修正：

- 查询地点添加非空检查和UriEncode参数
- 详情校验SelectionIndex后按键显示
- 空结果清旧详情、取消选择并显示0项

实际全局变量：`请求中`、`当前URL`、`地点结果`、`地点名称`、`响应数据`。

### 过程职责（教师参考）

- `查询地点`：校验q非空；Url←/api/v1/places?q=UriEncode(trim输入)；禁用请求；Get。
- `显示地点结果(列表)`：保存地点结果；生成name显示列表；清详情；显示数量。

### 三组真实积木截图

1. `查询地点`：编码的是trim后的参数值，不是整个URL。
2. `显示地点结果`：保留完整字典列表，仅取name生成显示列表。
3. `PlacesView.AfterPicking`：有效索引先于取字典，空结果不沿用旧详情。

### 设备与验证边界

使用随课Python课堂服务，HostBox只填电脑局域网IPv4。示例不是公网服务；手机上的127.0.0.1指手机自身。服务的自动测试不等于Android客户端真机联调。 查询教师提供的校园地点示例，不访问真实地图或采集位置。显示名称与原始字典保持同序。

- 教师电脑运行配套Python标准库API，手机与电脑在可互通的同一局域网。
- 电脑本机可用127.0.0.1；手机必须填写教师电脑局域网IPv4，不能填127.0.0.1。
- HTTP用于隔离的课堂教学数据，不填写真实个人资料；Android明文HTTP兼容性以本平台打包结果实测。

### 共用课堂服务

教师使用随课 `teaching-api/teaching_server.py`；Python 3.8或3.13均可，无需第三方库。先在电脑浏览器核对欢迎接口。手机课堂运行 `python teaching_server.py --host 0.0.0.0`，使用电脑实际局域网IPv4。HostBox仅填IP，例如192.168.1.8；工程初值192.168.1.10是示例，不是固定地址。不要填协议、端口或路径；端口8765和接口路径由积木拼接。手机与电脑需在可互通的教学局域网，手机的127.0.0.1表示手机自身。

可重复故障：先停止当前服务，再加 `--scenario delay`（GET延迟6秒，对照APP超时5秒）、`error`（GET 500）、`empty`（空公告/活动）、`invalid-json`（坏JSON）。恢复用 `--scenario normal`。普通AIA按钮即可触发，不改HostBox为路径，也无需物理断网。POST超时不自动重发；先查结果再决定是否重试。示例仅教学数据，无账号权限系统，勿作为生产留言平台。

## 核心任务与参考答案

### 任务1：补查询编码

1. 在查询地点中校验trim关键词非空。
2. 只对参数值调用Http.UriEncode。
3. 拼接/api/v1/places?q=与编码结果，再Get。
4. 中文图书前后加空格仍应查询图书角。

提问：可以把整个URL都UriEncode吗？

参考：不应，协议和路径分隔符要保留，只编码查询参数值。

### 任务2：核对结果刷新与空表

1. 阅读已给显示地点结果主体。
2. 新结果先清详情、取消旧选择。
3. 确认名称列表与地点字典列表顺序一致。
4. 0项时显示数量0，不继续显示旧地点。

提问：名称列表能单独排序而不调整原数据吗？

参考：不能直接这样做，否则同一索引会指向不同地点。

### 任务3：补选择详情

1. 添加PlacesView.AfterPicking，校验索引。
2. 按同一位置取地点字典。
3. 读name、floor、note并组成详情。
4. 先选正常结果，再查不存在，核对详情清空。

提问：SelectionIndex=0时为何不取记录？

参考：0表示无有效选择，读取会越界。

## 组件与程序核对

| 名称 | 类型 | 教学作用 |
| --- | --- | --- |
| HostBox | TextBox | 教师电脑局域网IPv4地址 |
| RequestButton | Button | 发起本课请求 |
| StatusLabel | Label | 请求与错误状态 |
| QueryBox | TextBox | 地点关键词 |
| PlacesView | ListView | 匹配地点名称 |
| DetailLabel | Label | 楼层及开放提示 |
| Http | Web | 教学HTTP客户端 |

- 当 `RequestButton.Click`：查询地点。
- 当 `Http.GotText`：200时解码并读取items；显示地点结果；400则提示关键词；其他码报告错误；恢复按钮。
- 当 `PlacesView.AfterPicking`：使用SelectionIndex读取地点字典的name、floor、note。
- 当 `Http.TimedOut`：恢复并显示超时。
