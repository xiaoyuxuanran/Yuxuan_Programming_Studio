# 第39课｜制作信息查询工具

这是一份90分钟课程的教学内容源稿，项目为**中文编码查询与地点详情**。

校园地点查询：输入关键词查找教室与活动地点，显示名称、楼层和开放提示。

## 建议阅读顺序

1. 教师教案：了解本课目标、90分钟安排和答疑。
2. 学生任务单：按支架任务预测、制作、互测。
3. PPT：文字与表格可编辑，逐页教师备注对应本教案。
4. AIA：先发Class版，完成后再对照完整答案。

## 三个工程版本

| 版本 | 内容 |
| --- | --- |
| 完整答案 | YXCourse39.aia：完整参考答案，含本课全部交互。 |
| 课堂支架 | YXCourse39Class.aia：保留请求响应解码与items类型验证、显示地点结果主体列表生成、结束请求和错误恢复；查询与详情占位；查询地点添加非空检查和UriEncode参数；详情校验SelectionIndex后按键显示；空结果清旧详情、取消选择并显示0项。 |
| 纯界面起始版 | YXCourse39Starter.aia：组件、初始属性与素材齐全，没有积木。 |

## 当前内容说明

`content.json` 是PPT与课程包装配的结构化源内容；此目录中的“工程名”描述交付规格，实际AIA/PPT/截图由制作流程装配到最终输出目录。不能据此声称导入、编译或设备运行已经通过。查看最终课程包的验证说明确认验证范围。

导入路径：平台App Inventor → 项目 → 导入项目(.aia)。设计器预览不执行程序；运行需课堂已有Android环境。项目内部名采用英文数字以保持兼容；屏幕上的中文文字不受此限制。
