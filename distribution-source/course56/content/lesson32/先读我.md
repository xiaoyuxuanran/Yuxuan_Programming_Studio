# 第32课｜用字典描述一条记录

这是一份90分钟课程的教学内容源稿，项目为**列表中存放植物字典并编辑字段**。

校园植物卡：用名称、地点、特征三个键保存一条观察记录，选择后编辑特征。

## 建议阅读顺序

1. 教师教案：了解本课目标、90分钟安排和答疑。
2. 学生任务单：按支架任务预测、制作、互测。
3. PPT：文字与表格可编辑，逐页教师备注对应本教案。
4. AIA：先发Class版，完成后再对照完整答案。

## 三个工程版本

| 版本 | 内容 |
| --- | --- |
| 完整答案 | YXCourse32.aia：完整参考答案，含本课全部交互。 |
| 课堂支架 | YXCourse32Class.aia：保留两条植物字典及辅助变量、刷新名称和全部事件入口、显示记录、保存特征的占位过程；显示记录按键读取，缺键显示未填写；保存特征只更改选中的那一份字典；验证另一条记录不受影响。 |
| 纯界面起始版 | YXCourse32Starter.aia：组件、初始属性与素材齐全，没有积木。 |
