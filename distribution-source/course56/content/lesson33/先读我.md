# 第33课｜关闭 APP 后还能记住

这是一份90分钟课程的教学内容源稿，项目为**TinyDB阅读持久化**。

阅读打卡本：保存累计分钟数与最近一次阅读内容，重新打开仍能恢复。

## 建议阅读顺序

1. 教师教案：了解本课目标、90分钟安排和答疑。
2. 学生任务单：按支架任务预测、制作、互测。
3. PPT：文字与表格可编辑，逐页教师备注对应本教案。
4. AIA：先发Class版，完成后再对照完整答案。

## 三个工程版本

| 版本 | 内容 |
| --- | --- |
| 完整答案 | YXCourse33.aia：完整参考答案，含本课全部交互。 |
| 课堂支架 | YXCourse33Class.aia：保留全部变量、刷新阅读、恢复阅读、输入校验与Save按钮调用、保存阅读占位仅刷新显示；保存阅读加入totalMinutes、lastBook的StoreValue；添加ResetButton.Click，ClearTag后重置变量与显示；模拟重开并比较首次默认和旧记录。 |
| 纯界面起始版 | YXCourse33Starter.aia：组件、初始属性与素材齐全，没有积木。 |

## 当前内容说明

`content.json` 是PPT与课程包装配的结构化源内容；此目录中的“工程名”描述交付规格，实际AIA/PPT/截图由制作流程装配到最终输出目录。不能据此声称导入、编译或设备运行已经通过。查看最终课程包的验证说明确认验证范围。

导入路径：平台App Inventor → 项目 → 导入项目(.aia)。设计器预览不执行程序；运行需课堂已有Android环境。项目内部名采用英文数字以保持兼容；屏幕上的中文文字不受此限制。
