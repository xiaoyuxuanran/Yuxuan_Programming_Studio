# 第36课｜让数据讲故事

这是一份90分钟课程的教学内容源稿，项目为**柱状图与7天阅读统计**。

一周阅读仪表板：七天分钟数转成柱状图，计算总量、平均值和最高日。

## 建议阅读顺序

1. 教师教案：了解本课目标、90分钟安排和答疑。
2. 学生任务单：按支架任务预测、制作、互测。
3. PPT：文字与表格可编辑，逐页教师备注对应本教案。
4. AIA：先发Class版，完成后再对照完整答案。

## 三个工程版本

| 版本 | 内容 |
| --- | --- |
| 完整答案 | YXCourse36.aia：完整参考答案，含本课全部交互。 |
| 课堂支架 | YXCourse36Class.aia：保留七天数据及所有辅助变量、日期选择、更新校验和事件入口、刷新统计占位、刷新图表仅Clear；刷新统计遍历累加，日均除7，最高并列取第一天；刷新图表Clear后加7个点，列表索引i对应图表X=i-1；修改周三为20，观察图表与统计同步。 |
| 纯界面起始版 | YXCourse36Starter.aia：组件、初始属性与素材齐全，没有积木。 |
