# 第2课｜会互动的数字名片

这是一份90分钟课程的教学内容源稿，项目为**我的数字名片**。

名片用虚构的“林小羽”和品牌标志头像介绍自己；“我的介绍”与“我的爱好”同时更新分类标题NameLabel及正文InfoLabel，“回到名片首页”恢复两处初始文字。

## 建议阅读顺序

1. 教师教案：了解本课目标、90分钟安排和答疑。
2. 学生任务单：按支架任务预测、制作、互测。
3. PPT：文字与表格可编辑，逐页教师备注对应本教案。
4. AIA：先发Class版，完成后再对照完整答案。

## 三个工程版本

| 版本 | 内容 |
| --- | --- |
| 完整答案 | Course02Card.aia：介绍、爱好、重置三个按钮事件完整。 |
| 课堂支架 | Course02CardClass.aia：界面、品牌标志头像与IntroButton.Click演示已给出；学生补HobbyButton.Click和ResetButton.Click，每个事件同步更新NameLabel与InfoLabel。 |
| 纯界面起始版 | Course02CardStarter.aia：保留相同界面、头像及初始属性，无任何积木。 |

## 当前内容说明

`content.json` 是PPT与课程包装配的结构化源内容；此目录中的“工程名”描述交付规格，实际AIA/PPT/截图由制作流程装配到最终输出目录。不能据此声称导入、编译或设备运行已经通过。查看最终课程包的验证说明确认验证范围。

导入路径：平台App Inventor → 项目 → 导入项目(.aia)。设计器预览不执行程序；运行需课堂已有Android环境。项目内部名采用英文数字以保持兼容；屏幕上的中文文字不受此限制。
