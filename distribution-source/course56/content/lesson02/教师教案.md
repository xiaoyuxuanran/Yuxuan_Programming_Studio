# 第2课｜会互动的数字名片

**项目：我的数字名片　时长：90分钟　配套课件：24页**

## 课前准备

本课采用“体验—预测—制作—改编—分享”的节奏。先向学生发课堂支架版，完成后再对照答案。纯界面版用于课后重建，避免90分钟都用于重复搭界面。

| 版本 | 内容 |
| --- | --- |
| 完整答案 | Course02Card.aia：介绍、爱好、重置三个按钮事件完整。 |
| 课堂支架 | Course02CardClass.aia：界面、品牌标志头像与IntroButton.Click演示已给出；学生补HobbyButton.Click和ResetButton.Click，每个事件同步更新NameLabel与InfoLabel。 |
| 纯界面起始版 | Course02CardStarter.aia：保留相同界面、头像及初始属性，无任何积木。 |

运行使用教师已配置的Android设备或模拟器；组件设计器不执行点击逻辑。无设备时仍可做积木分析，但任务单的运行结果须写“待测”。

## 学习目标与达标证据

1. 用Image、Label和Button分别组织图像、信息与操作。
2. 通过不同按钮的Click事件改变同一个InfoLabel.Text。
3. 保护个人信息，制作一张别人能够自主操作的介绍卡。

## 示例边界

名片用虚构的“林小羽”和品牌标志头像介绍自己；“我的介绍”与“我的爱好”同时更新分类标题NameLabel及正文InfoLabel，“回到名片首页”恢复两处初始文字。

名片不填写真实电话、家庭地址或账号密码；本课不做登录、二维码或联网名片。示例头像为用户提供的羽轩品牌标志；改编可使用有许可的素材，不直接复制搜索图片。

## 核心任务与参考答案

### 任务1：认出名片的组成

1. 导入 Course02CardClass.aia，找到AvatarImage、NameLabel、InfoLabel及三个按钮。
2. 选AvatarImage查看Picture，核对图片文件在媒体区存在。
3. 阅读“我的介绍”按钮的积木，圈出目标组件与属性。

提问：Picture里的文件名和InfoLabel.Text里的介绍文字，分别给哪个组件用？

参考：Picture为Image提供图片资源；InfoLabel.Text是标签显示的文字。

### 任务2：补全爱好按钮

1. 从HobbyButton取出Click事件。
2. 设置InfoLabel.Text为“我的爱好：画画、阅读和编程。我想做一个帮助同学的小工具。”或自己的公开兴趣。
3. 同时设置NameLabel.Text为“林小羽｜我的爱好”，使分类标题和正文一致。
4. 在运行环境交替点“我的介绍”和“我的爱好”，观察只有信息区变化。

提问：为什么两个按钮可以设置同一个标签？

参考：每个按钮的事件在被点击时执行，分别为同一标签写入新文字，最后一次设置决定当前显示。

### 任务3：补重置并安全改编

1. 添加ResetButton.Click，同时把InfoLabel.Text恢复“欢迎认识我！点击下面的按钮。”、NameLabel.Text恢复“林小羽｜创意小队”。
2. 只使用昵称、公开兴趣和许可头像，避免真实联系方式。
3. 测试长文字与不同点击顺序，然后导出AIA。

提问：改了设计器里的初始提示，重置事件需要改吗？

参考：需要同步；重置事件写入自己的文字值，不会自动读取原来的设计属性。

## 组件与程序核对

| 名称 | 类型 | 教学作用 |
| --- | --- | --- |
| AvatarImage | Image | 显示打包进工程的头像图片 |
| NameLabel | Label | 显示姓名与当前介绍分类 |
| InfoLabel | Label | 显示介绍、爱好或初始提示 |
| IntroButton | Button | 显示自我介绍 |
| HobbyButton | Button | 显示兴趣内容 |
| ResetButton | Button | 恢复提示 |

- 当 `IntroButton.Click`：NameLabel.Text ← 林小羽｜关于我；InfoLabel.Text ← 大家好，我是林小羽。我喜欢提出问题，也喜欢把想法做成作品。。
- 当 `HobbyButton.Click`：NameLabel.Text ← 林小羽｜我的爱好；InfoLabel.Text ← 我的爱好：画画、阅读和编程。我想做一个帮助同学的小工具。。
- 当 `ResetButton.Click`：NameLabel.Text ← 林小羽｜创意小队；InfoLabel.Text ← 欢迎认识我！点击下面的按钮。。

## 常见问题

| 现象或误解 | 排查提示 |
| --- | --- |
| 点爱好后按钮文字改变了 | 属性设置选成了HobbyButton.Text，应设置InfoLabel.Text。 |
| 头像不显示 | 核对Picture文件名、大小写与媒体资源，不把本机绝对路径填作打包素材。 |
| 文字变长后显示不全 | 检查标签宽度和高度，优先自动高度、适当留白，不只缩小字体。 |
| 切换后正文变了但分类标题没变 | 检查是否遗漏NameLabel.Text设置；每个按钮都要同步处理标题和正文。 |

## 分层与评价

- **基础：**补完爱好和重置，三条路径都可解释。
- **提高：**为有兴趣了解你的新同学改写介绍，让信息简短且有层次。
- **拓展：**增加一个“我的作品”按钮展示一项真实完成的作品；只发布适合公开的信息。

建议功能与规则4分、概念解释2分、测试修正2分、工程保存2分。未完成设备运行的项目，运行分保持待评。

## 出口题参考

1. 两个按钮都设置InfoLabel.Text，最后屏幕由哪个事件决定？
   参考：最近一次实际执行的设置决定当前文字。
2. 能否把家庭地址写到班级公开名片？为什么？
   参考：不应把家庭地址等敏感信息放入公开名片；用昵称和公开兴趣表达自己。
3. 头像图片为什么要在工程媒体区存在？
   参考：打包时工程需包含资源，才能在运行环境按Picture路径显示。
