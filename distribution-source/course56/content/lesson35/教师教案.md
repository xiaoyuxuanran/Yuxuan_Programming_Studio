## 课堂支架与实际程序核对

已给结构：

- 示例记录、辅助变量与刷新记录
- 全部操作入口、导入提交的类型保护和分享保护
- 导出CSV与验证导入占位；错误恢复

学生要补或修正：

- 用原生CSV转换而非手工逗号分割
- 验证导入使用局部临时表，全部成功才返回列表
- 补BackupFile.AfterFileSaved，MakeFullPath后启用分享

实际全局变量：`记录`、`导出完成`、`写入中`、`备份路径`、`显示记录`、`导出表`、`导入结果`。

### 过程职责（教师参考）

- `导出CSV`：在表头后追加记录；list to csv table；PreviewBox显示；导出完成false；SaveFile文本到reading.csv。
- `验证导入(表)`：表头完全匹配；至少表头；每数据行恰好两列，title非空，minutes为1..240整数；在临时表中转换数值；全部成功返回临时表。
- `刷新记录`：将每行转成书名+分钟的显示列表。

### 三组真实积木截图

1. `导出CSV`：原生list to csv table生成文本；写入开始先撤销旧分享许可。
2. `验证导入`：验证导入返回列表或错误说明，调用者按返回类型决定是否提交。
3. `BackupFile.AfterFileSaved`：回调才恢复状态；完整路径通过MakeFullPath取得，不硬编码Android目录。

## 核心任务与参考答案

### 任务1：补原生CSV导出

1. 找到导出CSV占位过程。
2. 建表头title、minutes并追加各条记录。
3. list to csv table得到文本，显示并SaveFile。
4. 先设导出完成假、写入中真，禁用分享。

提问：书名地球,我们的家能直接按逗号切开吗？

参考：不能，CSV引号规则由原生转换处理。

### 任务2：补整表验证

1. 检查表头完全匹配，每行两列。
2. 标题trim非空，分钟为1到240整数。
3. 在局部临时表转换；全部通过才返回列表。
4. 坏行返回原因，只有表头返回空列表。

提问：第一行有效、第二行错误能先导入第一行吗？

参考：本课整次导入作为一个操作，失败时不提交任何部分。

### 任务3：补保存回调和分享准备

1. 添加BackupFile.AfterFileSaved。
2. 用App作用域和reading.csv调用MakeFullPath。
3. 记录完整路径，恢复导出键并启用分享。
4. 保存前点击分享不能调用ShareFile。

提问：SaveFile调用后为何不能立刻分享？

参考：写入异步完成，应在AfterFileSaved后确认可分享。

## 组件与程序核对

| 名称 | 类型 | 教学作用 |
| --- | --- | --- |
| PreviewBox | TextBox | 显示或粘贴CSV |
| ExportButton | Button | 生成CSV并写文件 |
| ImportButton | Button | 验证并导入CSV文本 |
| ShareButton | Button | 分享已写好的备份 |
| RowsView | ListView | 当前记录 |
| StatusLabel | Label | 导入导出结果 |
| BackupFile | File | App作用域备份 |
| Share1 | Sharing | 系统分享面板 |

- 当 `ExportButton.Click`：导出CSV。
- 当 `BackupFile.AfterFileSaved`：写入中时用MakeFullPath(App,reading.csv)保存完整路径；导出完成真，恢复导出并启用分享。
- 当 `ImportButton.Click`：list from csv table解析PreviewBox；验证成功才替换记录并刷新；失败保留旧数据。
- 当 `ShareButton.Click`：导出完成时Sharing.ShareFile(BackupFile.MakeFullPath(App,reading.csv))。
- 当 `Screen1.ErrorOccurred`：显示格式或文件错误，保留原数据。
