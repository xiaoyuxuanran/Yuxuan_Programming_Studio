# 第35课｜数据导入、导出与分享

这是一份90分钟课程的教学内容源稿，项目为**CSV原子导入、App文件备份与分享**。

阅读备份工具：把书名和分钟数导出CSV，再从文本导入并分享备份文件。

## 建议阅读顺序

1. 教师教案：了解本课目标、90分钟安排和答疑。
2. 学生任务单：按支架任务预测、制作、互测。
3. PPT：文字与表格可编辑，逐页教师备注对应本教案。
4. AIA：先发Class版，完成后再对照完整答案。

## 三个工程版本

| 版本 | 内容 |
| --- | --- |
| 完整答案 | YXCourse35.aia：完整参考答案，含本课全部交互。 |
| 课堂支架 | YXCourse35Class.aia：保留示例记录、辅助变量与刷新记录、全部操作入口、导入提交的类型保护和分享保护、导出CSV与验证导入占位；错误恢复；用原生CSV转换而非手工逗号分割；验证导入使用局部临时表，全部成功才返回列表；补BackupFile.AfterFileSaved，MakeFullPath后启用分享。 |
| 纯界面起始版 | YXCourse35Starter.aia：组件、初始属性与素材齐全，没有积木。 |

## 当前内容说明

`content.json` 是PPT与课程包装配的结构化源内容；此目录中的“工程名”描述交付规格，实际AIA/PPT/截图由制作流程装配到最终输出目录。不能据此声称导入、编译或设备运行已经通过。查看最终课程包的验证说明确认验证范围。

导入路径：平台App Inventor → 项目 → 导入项目(.aia)。设计器预览不执行程序；运行需课堂已有Android环境。项目内部名采用英文数字以保持兼容；屏幕上的中文文字不受此限制。
