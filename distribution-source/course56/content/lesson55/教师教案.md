# 第55课｜同伴测试与迭代

**项目：阅读搭子 0.5：删除确认与一次撤销　时长：90分钟　配套课件：24页**

## 学习目标与达标证据

1. 空输入、越界分钟、重复未完成计划。
2. 保存被删记录和原始位置。
3. 用测试记录验证同伴测试与迭代的核心规则。

### 过程职责（教师参考）

- `请求删除`：保存待删序号；ShowChooseDialog含书名、删除/取消。
- `确认删除`：合法待删序号下保存完整记录和原位置，删除、开启一次撤销并保存。
- `撤销删除`：可撤销为真才插回合法位置，清可撤销并保存。
- `校验输入`：trim书名非空且≤40字，分钟1～180整数。
- `新增计划`：校验后遍历，拒绝title相同且done=false记录；其余按原流程追加。

### 三组真实积木截图

1. `新增计划`：新增计划已给；任务一通过边界测试检查新规则。
2. `Confirm.AfterChoosing`：AfterChoosing已给，确认删除过程待补。
3. `撤销删除`：撤销删除待补；只撤销当前运行最近一次。

## 核心任务与参考答案

### 任务1：阅读新增保护并设计回归表

1. 新增计划已给，追踪校验输入与未完成重名遍历。
2. 同名未完成再次保存，数量不变。
3. 同名已完成允许新建目标。
4. 比较0、180、181及空白书名；写出实际结果。

提问：新规则是否禁止再次阅读同一本书？

参考：不是，只防止同名未完成任务重复，已完成可以创建新目标。

### 任务2：补确认删除

1. 请求删除和Confirm.AfterChoosing入口已给。
2. 确认删除先验待删序号范围。
3. 保存目标记录与原位置，remove该项。
4. 可撤销←真，调用保存并刷新；取消不得改数据。

提问：点击删除按钮为什么不能立即remove？

参考：需等用户明确选择删除；取消和关闭应保留原计划。

### 任务3：补一次撤销并同伴互测

1. 仅可撤销为真时继续。
2. 恢复位置限制在1到列表长度+1。
3. insert最近删除记录，再可撤销←假并保存。
4. 删除第二条→取消、删除第二条→撤销分别记录；第二次撤销不可用。

提问：只记书名能完整撤销吗？

参考：不能，还要恢复整条记录与原位置，保留分钟和完成状态。

## 出口题参考

1. 为什么保留待删记录？
   参考：确认是异步回调，必须明确本次操作的目标。
2. 撤销为什么先限插入位置？
   参考：列表长度可能改变，插入位置必须合法。
3. 重启后还能撤销旧删除吗？
   参考：本版本不持久化撤销历史，重启后不能。
