# 第20课｜接物游戏：完善规则

这是一份90分钟课程的教学内容源稿，项目为**三生命与递增难度接苹果**。

接续第19课接苹果。初始3生命，漏接扣1；每5分下落步长加1，最大12。暂停保留位置，生命0结束并显示最终分数，重新开始恢复0分3命。

## 建议阅读顺序

1. 教师教案：了解本课目标、90分钟安排和答疑。
2. 学生任务单：按支架任务预测、制作、互测。
3. PPT：文字与表格可编辑，逐页教师备注对应本教案。
4. AIA：先发Class版，完成后再对照完整答案。

## 三个工程版本

| 版本 | 内容 |
| --- | --- |
| 完整答案 | YXCourse20.aia：完整参考答案，含本课全部交互。 |
| 课堂支架 | YXCourse20Class.aia：保留第19课的移动、接取、开始/暂停/继续机制、全部新增变量和面板、重新开始、重置苹果、移动篮子、调整难度和结束游戏的占位过程；FallClock.Timer漏接先扣生命再判断结束；调整难度改为min(12,5+floor(得分/5))；结束游戏停止Clock、隐藏苹果、禁用开始并显示最终分。 |
| 纯界面起始版 | YXCourse20Starter.aia：组件、初始属性与素材齐全，没有积木。 |
