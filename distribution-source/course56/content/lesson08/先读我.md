# 第8课｜随身计算小工具

这是一份90分钟课程的教学内容源稿，项目为**厘米与米换算器**。

输入非负长度，点击厘米转米或米转厘米，显示数值和单位。空白、非数字与负数分别得到提示；清空恢复等待输入。

## 建议阅读顺序

1. 教师教案：了解本课目标、90分钟安排和答疑。
2. 学生任务单：按支架任务预测、制作、互测。
3. PPT：文字与表格可编辑，逐页教师备注对应本教案。
4. AIA：先发Class版，完成后再对照完整答案。
