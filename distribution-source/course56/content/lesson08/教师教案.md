# 第8课｜随身计算小工具

**项目：厘米与米换算器　时长：90分钟　配套课件：24页**

## 学习目标与达标证据

1. 依据1米等于100厘米选择0.01或100的倍率。
2. 阅读文本输入、数值运算与单位连接的完整路径。
3. 补米转厘米与清空，测试有效、无效和边界输入。

## 示例边界

输入非负长度，点击厘米转米或米转厘米，显示数值和单位。空白、非数字与负数分别得到提示；清空恢复等待输入。

Class版已提供完整换算(倍率,单位)过程及输入检查，学生主要通过给定参数完成反方向换算和清空。输入检查结构先观察，第9课再重点学习条件判断。

## 核心任务与参考答案

### 任务1：读出厘米转米示范

1. 导入Class版，找到ToMeterButton.Click。
2. 读出调用换算时传入倍率0.01、单位米。
3. 输入125、100和0，分别预测再测试。

提问：为什么125转米不是12500？

参考：厘米转米要除100，即乘0.01；数值应为1.25米。

### 任务2：补米转厘米

1. 添加ToCmButton.Click。
2. 调用已有换算过程，传入倍率100与文字厘米。
3. 输入1.25，点击米转厘米，并与125厘米对照。

提问：把倍率写成100却仍传入单位米，会怎样？

参考：数值计算可能正确放大，但结果标错单位；数值和单位参数必须成对对应方向。

### 任务3：清空并测错误输入

1. 添加ClearButton.Click，清空InputBox.Text、把输入值设0、把ResultLabel.Text设为等待输入。
2. 测试空白、abc、-1，分别记录提示。
3. 清空后输入2再转厘米，检查没有沿用旧输入。

提问：清空为什么要处理输入框和结果两处？

参考：只清结果仍留下旧输入，用户易以为没有清空；只清输入仍残留旧结果，也会误导。

## 组件与程序核对

| 名称 | 类型 | 教学作用 |
| --- | --- | --- |
| InputBox | TextBox | 输入长度 |
| ToMeterButton | Button | 厘米转米 |
| ToCmButton | Button | 米转厘米 |
| ResultLabel | Label | 显示数值和单位 |
| ClearButton | Button | 清空 |

- 当 `ToMeterButton.Click`：换算(0.01,'米')。
- 当 `ToCmButton.Click`：换算(100,'厘米')。
- 当 `ClearButton.Click`：清输入；结果='等待输入'。

## 过程定义的教学核对

- `换算(倍率,单位)`：先检查trim后的输入非空且is number；有效时结果=输入*倍率并显示单位，否则显示请输入数字。

## 常见问题

| 现象或误解 | 排查提示 |
| --- | --- |
| 结果大了10000倍 | 厘米转米误用100；应为0.01。 |
| 数值对，单位错 | 检查调用过程的单位参数。 |
| 空白进入运算 | 保留已给的输入检查顺序。 |
| 清空后旧输入仍在 | InputBox.Text与结果都需要处理。 |

## 分层与评价

- **基础：**完成米转厘米和清空，正确测试125、1.25、0与错误输入。
- **提高：**设计一个带两种方向的换算任务，先在纸上写单位关系再改倍率。
- **拓展：**为克与千克另加一对按钮；保留非负规则和清空，并记录倍率与单位。

建议功能与规则4分、概念解释2分、测试修正2分、工程保存2分。未完成设备运行的项目，运行分保持待评。
