# 第28课｜手机知道我在哪里

这是一份90分钟课程的教学内容源稿，项目为**经纬度、精度、速度与方位观察站**。

位置观察站：显示经纬度、精度和移动速度，主动开始与停止观察。

## 建议阅读顺序

1. 教师教案：了解本课目标、90分钟安排和答疑。
2. 学生任务单：按支架任务预测、制作、互测。
3. PPT：文字与表格可编辑，逐页教师备注对应本教案。
4. AIA：先发Class版，完成后再对照完整答案。

## 三个工程版本

| 版本 | 内容 |
| --- | --- |
| 完整答案 | YXCourse28.aia：完整参考答案，含本课全部交互。 |
| 课堂支架 | YXCourse28Class.aia：保留全部变量、停止观察、显示位置完整过程、开始与停止按钮入口、位置服务状态、方位角回调、开始观察过程占位；开始观察设置状态、清旧提示并启用两个传感器；添加Location1.LocationChanged，仅观察中时保存并显示数据；添加Screen1.PermissionDenied，停止观察并提示权限设置。 |
| 纯界面起始版 | YXCourse28Starter.aia：组件、初始属性与素材齐全，没有积木。 |

## 当前内容说明

`content.json` 是PPT与课程包装配的结构化源内容；此目录中的“工程名”描述交付规格，实际AIA/PPT/截图由制作流程装配到最终输出目录。不能据此声称导入、编译或设备运行已经通过。查看最终课程包的验证说明确认验证范围。
