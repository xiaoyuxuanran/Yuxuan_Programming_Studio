## 学习目标与达标证据

1. 纬度约在-90到90，经度约在-180到180。
2. 开始观察前不启用位置组件。
3. 用测试记录验证手机知道我在哪里的核心规则。

## 示例边界

位置观察站：显示经纬度、精度和移动速度，主动开始与停止观察。

本课只在本机观察位置，不反向地理编码或上传。室内等待和精度取决于设备服务。0,0可以是合法经纬度；是否有效由回调与有位置标志判断。

## 课堂支架与实际程序核对

已给结构：

- 全部变量
- 停止观察、显示位置完整过程
- 开始与停止按钮入口
- 位置服务状态、方位角回调
- 开始观察过程占位

学生要补或修正：

- 开始观察设置状态、清旧提示并启用两个传感器
- 添加Location1.LocationChanged，仅观察中时保存并显示数据
- 添加Screen1.PermissionDenied，停止观察并提示权限设置

实际全局变量：`观察中`、`有位置`、`最近纬度`、`最近经度`。

### 过程职责（教师参考）

- `开始观察`：观察中true；有位置false；清旧提示；Location1与Compass.Enabled true。
- `停止观察`：观察中false；两传感器Enabled false；标明最后一次位置而非实时。
- `显示位置(纬度,经度,速度)`：更新数值；显示Accuracy与当前时间；有位置true。

### 三组真实积木截图

1. `开始观察`：Class保留按钮入口但开始观察过程待补。位置与方位传感器都须按用户操作启停。
2. `Location1.LocationChanged`：显示位置已给出；包含SpeedLabel与精度未知保护。接收时刻表示本机收到回调，不宣称测量绝对准确。
3. `Screen1.PermissionDenied`：权限拒绝后先停观察再提示，所有操作入口仍可继续。具体权限行为由Android课堂设备另验。

### 设备与验证边界

本课只在本机观察位置，不反向地理编码或上传。室内等待和精度取决于设备服务。0,0可以是合法经纬度；是否有效由回调与有位置标志判断。

- 支持位置服务的Android手机；明确权限；不要求公开真实家庭或个人位置。

## 核心任务与参考答案

### 任务1：补开始观察过程

1. 找到Class中开始观察占位过程。
2. 观察中←真，有位置←假，清旧提示。
3. 启用Location1和Compass，显示等待位置。
4. 首次打开前不自动启用定位。

提问：为什么开始时重设有位置为假？

参考：防止旧数值被当作本次已经获得的新位置。

### 任务2：补实际位置回调

1. 添加Location1.LocationChanged。
2. 仅观察中时保存latitude、longitude。
3. 调用显示位置(latitude,longitude,speed)。
4. 阅读已给过程：speed单位m/s；HasAccuracy假显示精度未知。

提问：收到latitude=0、longitude=0能判定定位失败吗？

参考：不能；0,0可能是合法位置，成功回调才是有位置的证据。

### 任务3：补权限恢复并核对停止

1. 添加Screen1.PermissionDenied，停止观察并提示权限设置。
2. 阅读已给StatusChanged：它报告服务状态，不冒充新位置。
3. 有效结果后停止，核对两组件Enabled都为假。
4. 再来的位置回调应被忽略，页面标记最后结果。

提问：Location1.StatusChanged能替代LocationChanged吗？

参考：不能，服务状态变化没有提供本次经纬度，不应切成已定位。

## 组件与程序核对

| 名称 | 类型 | 教学作用 |
| --- | --- | --- |
| StartButton | Button | 开始位置观察 |
| StopButton | Button | 停止观察 |
| LatitudeLabel | Label | 纬度 |
| LongitudeLabel | Label | 经度 |
| AccuracyLabel | Label | 精度与更新时间 |
| HeadingLabel | Label | 方位角 |
| StatusLabel | Label | 等待权限和定位状态 |
| Location1 | LocationSensor | 获得位置 |
| Compass | OrientationSensor | 提供方位角 |
| TimeClock | Clock | 记录本地接收时刻 |
| SpeedLabel | Label | 显示位置回调速度，单位m/s |

- 当 `StartButton.Click`：开始观察。
- 当 `StopButton.Click`：停止观察。
- 当 `Location1.LocationChanged`：若观察中：保存latitude longitude；显示位置；速度标m/s。
- 当 `Location1.StatusChanged`：仅显示provider与status，不设置有位置、不替换经纬度。
- 当 `Compass.OrientationChanged`：观察中时显示azimuth方位角。
- 当 `Screen1.PermissionDenied`：停止观察；提示需要位置权限，可在系统设置调整。

- **基础：**完成课堂支架中的关键逻辑，记录一个正常和一个边界结果。
- **提高：**比较室内与室外定位精度，记录观察条件。

## 出口题参考

1. Accuracy未知时为什么不能显示0米？
   参考：0米会误导为极高精度；需检查HasAccuracy并写精度未知。
2. 速度与方位分别来自哪里？
   参考：速度来自位置回调speed，单位m/s；方位角来自Compass。
3. 停止后保留旧数值为什么必须标记？
   参考：避免使用者把最后一次位置误认为仍在实时更新。
