# 第15课｜手机涂鸦板

**项目：可选颜色与粗细的涂鸦板　时长：90分钟　配套课件：24页**

## 课前准备

本课采用“体验—预测—制作—改编—分享”的节奏。先向学生发课堂支架版，完成后再对照答案。纯界面版用于课后重建，避免90分钟都用于重复搭界面。

| 版本 | 内容 |
| --- | --- |
| 完整答案 | YXCourse15.aia：完整参考答案，含本课全部交互。 |
| 课堂支架 | YXCourse15Class.aia：保留选择画笔(颜色,宽度)、颜色与粗细四个按钮事件；添加PaintCanvas.Dragged，用prevX/prevY连接currentX/currentY；添加PaintCanvas.Touched，画线宽一半半径的实心圆；添加ClearButton.Click，调用Clear。 |
| 纯界面起始版 | YXCourse15Starter.aia：组件、初始属性与素材齐全，没有积木。 |

运行使用教师已配置的Android设备或模拟器；组件设计器不执行点击逻辑。无设备时仍可做积木分析，但任务单的运行结果须写“待测”。

## 学习目标与达标证据

1. 以画布左上为原点解释X向右、Y向下的坐标。
2. 用Dragged的上一点与当前点绘制连续短线。
3. 完成点按和清空，区分旧笔迹与当前画笔属性。

## 示例边界

在画布拖动画连续线，点按留圆点。可以选择天蓝或红色、2或10像素线宽；清空删除旧笔迹，但保留当前画笔设置。

Class版已给选择画笔过程和四个工具按钮事件，学生补Dragged、Touched及Clear。作品不包含保存图片功能，清空后的笔迹不能靠本工程恢复。

## 核心任务与参考答案

### 任务1：连接连续画线

1. 导入Class版，添加PaintCanvas.Dragged。
2. 调用PaintCanvas.DrawLine，四个坐标依次为prevX、prevY、currentX、currentY。
3. 画弯曲线，检查是否连续且不向同一点发散。

提问：为什么不能一直用startX、startY当每条线的起点？

参考：那会从最初触点向后续点画多条长线，容易形成扇形；应连接相邻两点。

### 任务2：读懂已给的画笔工具

1. 找到BlueButton、RedButton、ThinButton、ThickButton事件。
2. 先画蓝色细线，再切红色粗线，观察旧笔迹与新笔迹。
3. 检查ToolLabel的状态文字和文字颜色随当前画笔更新。

提问：改变PaintColor会把所有旧线一起变红吗？

参考：不会，画笔属性影响之后绘制的内容，已画出的旧笔迹保持原来颜色。

### 任务3：加入点按和清空

1. 添加PaintCanvas.Touched，调用DrawCircle(x,y,LineWidth/2,true)。
2. 添加ClearButton.Click，调用PaintCanvas.Clear。
3. 选红色粗笔，清空后点按，检查出现半径5的红色实心圆点。

提问：清空后为什么仍然是刚才选择的画笔？

参考：Clear清绘图，不会自动重置PaintColor与LineWidth；本作品规定保留工具选择。

## 组件与程序核对

| 名称 | 类型 | 教学作用 |
| --- | --- | --- |
| PaintCanvas | Canvas | 手指绘画区域 |
| BlueButton | Button | 选择天蓝画笔 |
| RedButton | Button | 选择红色画笔 |
| ThinButton | Button | 细线2像素 |
| ThickButton | Button | 粗线10像素 |
| ClearButton | Button | 清空画布 |
| ToolLabel | Label | 显示当前画笔 |

- 当 `PaintCanvas.Dragged`：DrawLine(prevX,prevY,currentX,currentY)。
- 当 `PaintCanvas.Touched`：DrawCircle(x,y,LineWidth/2,true)。
- 当 `BlueButton.Click`：PaintColor←天蓝；刷新提示。
- 当 `RedButton.Click`：PaintColor←红色；刷新提示。
- 当 `ThinButton.Click`：LineWidth←2。
- 当 `ThickButton.Click`：LineWidth←10。
- 当 `ClearButton.Click`：PaintCanvas.Clear。

## 常见问题

| 现象或误解 | 排查提示 |
| --- | --- |
| 弯线变成扇形 | DrawLine起点应为prevX、prevY。 |
| 点一下没有痕迹 | 补Touched与DrawCircle。 |
| 点按圆太大 | 检查半径是否误用完整LineWidth。 |
| 清空后工具显示不一致 | Clear只清笔迹；不要只改ToolLabel而不改实际属性。 |

## 分层与评价

- **基础：**完成连续线、点按和清空，解释工具只影响新笔迹。
- **提高：**设计一种新颜色工具，并保持ToolLabel与实际画笔同步。
- **拓展：**增加橡皮工具前先定义它是画背景色还是删除笔迹，记录背景变化时的限制。

建议功能与规则4分、概念解释2分、测试修正2分、工程保存2分。未完成设备运行的项目，运行分保持待评。
