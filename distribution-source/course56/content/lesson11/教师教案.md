# 第11课｜重复任务交给程序

**项目：乘法表与乘积总和　时长：90分钟　配套课件：24页**

本课采用“体验—预测—制作—改编—分享”的节奏。先向学生发课堂支架版，完成后再对照答案。纯界面版用于课后重建，避免90分钟都用于重复搭界面。

## 学习目标与达标证据

1. 解释循环变量从1到9、步长1的九次执行。
2. 补文本追加与乘积累计，区分循环前、循环中、循环后。
3. 用重复生成检查是否残留旧输出或旧总和。

## 示例边界

选择1～9中的一个整数，生成该数乘1到9的九行算式，并显示九个乘积的总和。重复生成先清空旧输出与总和。

Class版已提供输入检查、1～9循环框架、循环前清零和循环后显示。循环体里的自赋值是可连接的占位，学生替换为追加算式和累计；不要求学习列表。

## 核心任务与参考答案

### 任务1：读懂输入与循环框架

1. 导入Class版，找到GenerateButton.Click和生成乘法行过程。
2. 检查输入1～9整数后才调用过程，读循环起点1、终点9、步长1。
3. 在纸上写行3时i=1、2、9的算式。

提问：循环九次是不是要新建九个按钮？

参考：不是，同一次生成事件调用过程，循环在一次运行中执行九轮规则。

### 任务2：替换输出自赋值占位

1. 在循环体找到“输出←输出”的占位。
2. 改为连接旧输出、行、×、i、=、行×i和换行。
3. 输入3生成，检查从3×1到3×9恰好九行。

提问：为什么每次追加要读旧输出？

参考：只写当前算式会覆盖之前的行；连接旧输出才能保留前面内容并追加新行。

### 任务3：补累计并检查重复生成

1. 把“总和←总和”的占位改为总和+行×i。
2. 确认循环前已给的总和0与输出空仍保留。
3. 连续生成3两次，比较行数与总和；再生成1。

提问：总和归零放进循环体，会得到135吗？

参考：不会，每轮清零会丢掉此前累计，最后只保留3×9=27；归零应在循环前。

## 过程定义的教学核对

- `生成乘法行(行)`：清空输出和总和；for i 1..9步长1：追加行×i=积和换行，总和+=行*i；显示结果。

## 常见问题

| 现象或误解 | 排查提示 |
| --- | --- |
| 屏幕只剩最后一行 | 追加时没有连接旧输出。 |
| 连续生成后18行 | 循环前未清输出。 |
| 第二次总和270 | 循环前没有清零。 |
| 总和只有27 | 把清零放进循环体，每轮覆盖前面结果。 |

## 分层与评价

- **基础：**生成九行算式和正确总和，重复生成不累加旧结果。
- **提高：**把循环终点改为12，先预测行3总和234，再测试并同步范围说明。
- **拓展：**增加步长为2的奇数乘法练习，先列出会执行哪些i，再决定界面说明。

建议功能与规则4分、概念解释2分、测试修正2分、工程保存2分。未完成设备运行的项目，运行分保持待评。

## 出口题参考

1. 行是3，i从1到9，循环执行几次？
   参考：9次；行3是每轮乘数，不决定循环次数。
2. 输出←当前算式和输出←旧输出+当前算式有何区别？
   参考：前者覆盖，后者追加并保留旧行。
3. 清零、累加、显示分别应放哪里？
   参考：清零在循环前，累加在循环内，完整显示在循环后。
