# 第11课｜重复任务交给程序

这是一份90分钟课程的教学内容源稿，项目为**乘法表与乘积总和**。

选择1～9中的一个整数，生成该数乘1到9的九行算式，并显示九个乘积的总和。重复生成先清空旧输出与总和。

## 建议阅读顺序

1. 教师教案：了解本课目标、90分钟安排和答疑。
2. 学生任务单：按支架任务预测、制作、互测。
3. PPT：文字与表格可编辑，逐页教师备注对应本教案。
4. AIA：先发Class版，完成后再对照完整答案。

## 三个工程版本

| 版本 | 内容 |

| 完整答案 | YXCourse11.aia：完整参考答案，含本课全部交互。 |
| 课堂支架 | YXCourse11Class.aia：保留global 输出、总和、生成乘法行：清零、1～9循环框架和结果显示、GenerateButton.Click：合法性检查；把循环体的自赋值占位改成追加行×i=乘积与换行；在循环体累计总和；保留循环前清零，验证重复生成不叠加。 |
| 纯界面起始版 | YXCourse11Starter.aia：组件、初始属性与素材齐全，没有积木。 |
