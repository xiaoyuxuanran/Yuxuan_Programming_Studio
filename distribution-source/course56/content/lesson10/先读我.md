# 第10课｜随机数与猜数字

这是一份90分钟课程的教学内容源稿，项目为**1～20猜数字游戏**。

每局产生1～20的秘密整数，玩家输入猜测得到偏小、偏大或猜中提示。只计算有效猜测次数，猜中后保留结果，换一局清状态重新开始。

## 建议阅读顺序

1. 教师教案：了解本课目标、90分钟安排和答疑。
2. 学生任务单：按支架任务预测、制作、互测。
3. PPT：文字与表格可编辑，逐页教师备注对应本教案。
4. AIA：先发Class版，完成后再对照完整答案。
