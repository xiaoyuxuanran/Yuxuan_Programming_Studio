# 第7课｜会记数的 APP

这是一份90分钟课程的教学内容源稿，项目为**合作积分器**。

初始0分，完成合作挑战加1分，撤销一次减1分且最低为0；归零开始新一轮。数据保存在本次运行的全局变量中。

## 建议阅读顺序

1. 教师教案：了解本课目标、90分钟安排和答疑。
2. 学生任务单：按支架任务预测、制作、互测。
3. PPT：文字与表格可编辑，逐页教师备注对应本教案。
4. AIA：先发Class版，完成后再对照完整答案。

## 三个工程版本

| 版本 | 内容 |
| --- | --- |
| 完整答案 | YXCourse07.aia：完整参考答案，含本课全部交互。 |
| 课堂支架 | YXCourse07Class.aia：保留global 得分、刷新得分、AddButton.Click 的刷新调用；在 AddButton.Click 的刷新前加入累计赋值；添加 MinusButton.Click，限制最低 0 分；添加 ResetButton.Click，同时清变量和显示。 |
| 纯界面起始版 | YXCourse07Starter.aia：组件、初始属性与素材齐全，没有积木。 |
