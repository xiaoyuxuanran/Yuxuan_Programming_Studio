# 第38课｜读懂 JSON 数据

这是一份90分钟课程的教学内容源稿，项目为**JSON对象解码与缺字段默认值**。

班级公告卡：读取嵌套JSON，显示班级名称、公告标题与活动列表。

## 建议阅读顺序

1. 教师教案：了解本课目标、90分钟安排和答疑。
2. 学生任务单：按支架任务预测、制作、互测。
3. PPT：文字与表格可编辑，逐页教师备注对应本教案。
4. AIA：先发Class版，完成后再对照完整答案。

## 三个工程版本

| 版本 | 内容 |
| --- | --- |
| 完整答案 | YXCourse38.aia：完整参考答案，含本课全部交互。 |
| 课堂支架 | YXCourse38Class.aia：保留完整请求、结束请求与故障恢复、显示公告只保留顶层className默认读取、GotText占位与按钮入口；GotText在200时解码并检查字典；公告列表判空后再读首项title；activities不是列表时使用空列表，缺班名默认未命名班级。 |
| 纯界面起始版 | YXCourse38Starter.aia：组件、初始属性与素材齐全，没有积木。 |
