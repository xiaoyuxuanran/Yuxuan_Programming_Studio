# 第34课｜找到我需要的信息

这是一份90分钟课程的教学内容源稿，项目为**大小写无关的关键词筛选与结果索引映射**。

图书查找器：按书名关键词筛选本地图书表，空关键词显示全部，未找到明确提示。

## 建议阅读顺序

1. 教师教案：了解本课目标、90分钟安排和答疑。
2. 学生任务单：按支架任务预测、制作、互测。
3. PPT：文字与表格可编辑，逐页教师备注对应本教案。
4. AIA：先发Class版，完成后再对照完整答案。

## 三个工程版本

| 版本 | 内容 |
| --- | --- |
| 完整答案 | YXCourse34.aia：完整参考答案，含本课全部交互。 |
| 课堂支架 | YXCourse34Class.aia：保留三条图书字典和辅助变量、初始化、搜索、选择事件入口、筛选与显示详情占位；筛选过程实现trim/lower、contains和原序号收集；详情先读取结果索引再查原表；数量0时清旧详情并提示未找到。 |
| 纯界面起始版 | YXCourse34Starter.aia：组件、初始属性与素材齐全，没有积木。 |
