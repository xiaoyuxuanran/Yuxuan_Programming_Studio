## 核心任务与参考答案

### 任务1：补扫描并阅读订阅

1. 补开始扫描：先停止旧扫描与连接、清状态和列表。
2. StartScanning并开5秒ScanClock。
3. DeviceFound与停止事件已给，DeviceList进入ElementsFromString。
4. 阅读Connected中RegisterForStrings，区分扫描和通知订阅。

提问：BLE设备选择为什么用SelectionIndex连接？

参考：本扩展Connect接受扫描列表序号，显示列表必须与该索引一致。

### 任务2：补写入开关

1. 连接标志和IsDeviceConnected都真才写入。
2. WriteStringsWithResponse传服务UUID、RX UUID、false及单项文字列表。
3. 参数只传0或1，不加LF，NullTerminateStrings为false。
4. 等待设备通知，不把写完成当作灯已亮。

提问：StringsWritten等于设备应用确认吗？

参考：不等于，它只说明BLE写入操作完成，灯状态由TX通知协议确认。

### 任务3：补通知解析

1. StringsReceived入口已给，先核对服务及TX UUID。
2. 遍历stringValues，逐项交解析通知。
3. 消息必须是LED,0或LED,1才更新。
4. LED,9或未知字段不覆盖原状态。

提问：为什么不是用BluetoothClient的配对列表？

参考：BLE围绕扫描、服务和特征通信，不是经典SPP配对通道。

## 组件与程序核对

| 名称 | 类型 | 教学作用 |
| --- | --- | --- |
| ScanButton | Button | 开始5秒扫描 |
| OnButton | Button | 写入开灯 |
| OffButton | Button | 写入关灯 |
| DisconnectButton | Button | 主动断开 |
| StatusLabel | Label | 连接与服务状态 |
| Ble | BluetoothLE | MIT BLE扩展 |
| ScanClock | Clock | 扫描结束计时 |
| DevicePicker | ListPicker | 按扫描序号选择设备 |

- 当 `ScanButton.Click`：StartScanning；ScanClock开；提示扫描中。
- 当 `Ble.DeviceFound`：更新设备列表。
- 当 `ScanClock.Timer`：StopScanning；自身关闭。
- 当 `Ble.Connected`：RegisterForStrings(服务UUID,通知UUID,false)；控制启用。
- 当 `Ble.StringsReceived`：核对两个UUID；遍历stringValues，匹配LED,0/1再显示。
- 当 `Ble.ConnectionFailed`：清理并显示reason。
- 当 `Ble.Disconnected`：清理连接界面。
- 当 `OnButton.Click`：调用写入开关(文字1)。
- 当 `OffButton.Click`：调用写入开关(文字0)。
- 当 `DisconnectButton.Click`：Ble.Disconnect。
