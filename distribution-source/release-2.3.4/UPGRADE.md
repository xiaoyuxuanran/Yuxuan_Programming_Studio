# 升级到 2.3.4

保存项目并退出工作台、Mixly、Python/C++窗口。选择与当前版本匹配的更新包，安装到原目录。

| 当前版本 | 更新包 |
| --- | --- |
| 2.2.0 | `Yuxuan-Programming-Studio-Update-2.2.0-to-2.3.4.exe` |
| 2.3.1 | `Yuxuan-Programming-Studio-Update-2.3.1-to-2.3.4.exe` |
| 2.3.2 | `Yuxuan-Programming-Studio-Update-2.3.2-to-2.3.4.exe` |
| 2.3.3（含教学预览） | `Yuxuan-Programming-Studio-Update-2.3.3-to-2.3.4.exe` |
| 2.3.0 | 先升级到2.3.1，再使用对应包 |
| 首次安装 | 安装完整2.2.0，再使用2.2.0直升包 |

本次包含整套56课本地资料，更新包明显大于2.3.3的小型补丁。项目、依赖及激活信息保留，允许重复更新并合并卸载。升级前建议备份 `%LOCALAPPDATA%\AppInventorOffline` 和外部工程。

App Inventor项目页点击“教学项目”，按阶段、课次选择三种工程，或下载PPT/完整资料。教学项目副本首次打开后进入个人工作区；以后使用同一副本。若要保留原进度并重新开始，请先把已有副本另存为其他英文项目名。

Mixly沿用2.3.2/2.3.3的桌面版，无仿真。曾使用网页版的用户切换前请另存 `.mix`，桌面扩展需采用兼容格式。

优先访问 [Gitee发布页](https://gitee.com/studentcodeone/yuxuan_-programming_-studio/releases/tag/v2.3.4)，完整附件见 [GitHub发布页](https://github.com/xiaoyuxuanran/Yuxuan_Programming_Studio/releases/tag/v2.3.4)。只有验证上传成功的镜像才会写入更新清单；超出Gitee附件限制的整包由GitHub提供。所有更新包均检查大小与SHA256，手动下载可对照 `SHA256SUMS.txt`。
